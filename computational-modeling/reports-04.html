These are three reports for Assignment 4, Filtering to a Standard, written in three different styles. All three use the same example pack (crash test 9793, which no phrase assigns), so nothing here answers anybody's assignment. A Memo

Example 1 · Memo

To: Alice

Re: Crossmember peak for the customer

Data phrase: example pack (test 9793)

The peak to send is a deceleration of 437 m/s² (44.5 g) at 55.1 ms after impact, from the crossmember channel filtered at CFC 60. CFC is the channel frequency class, a number in SAE J211-1 that sets how much fast content the filter removes (a lower class removes more). I used CFC 60 because J211-1 gives that class to vehicle structure accelerations that are compared between vehicles, and a number going to a customer is most likely being compared with theirs. Here is a sentence you can paste:

"Peak X acceleration at the left rear seat crossmember (channel 10SEATLERE00ACXP, NHTSA test 9793): −437 m/s² (−44.5 g) at 55.1 ms after impact, filtered at CFC 60 per SAE J211-1, with the four-pole Butterworth filter run forward and then backward over the whole record."

Four things you should know before it goes out.

  • The unfiltered file says something very different. Read straight from the file, the channel peaks at −1919.8 m/s² (195.7 g) at 52.75 ms, about 4.4 times the filtered value. That spike is very narrow (see the figure). If the customer quotes a number near 196 g, they have not filtered.
  • Filtering once gives a slightly different answer. Running the filter forward only gives −442.2 m/s² (45.1 g) at 56.75 ms. The time is 1.65 ms late because a one-way filter delays everything. J211 asks for both directions, which is why the sentence says so.
  • A different class is right if the number is used differently. If the customer integrates this channel to get velocity or crush, J211 assigns CFC 180, and the peak at that class is −509.6 m/s² (51.9 g) at 53.35 ms. In that case the CFC 180 value is the right one to send.
  • The channel is one sensor on the seat crossmember. Our file calls it vehicle_x, which makes it sound like the whole car. The header says left rear seat crossmember, and the sentence uses the header's name and code so nobody mistakes it for the car's center of gravity.

Assumptions. The customer is comparing vehicle structure, which is why I chose CFC 60. I have not checked what class would apply if they are analyzing the crossmember itself. "The peak" is the largest value of either sign, and it is negative because the car is slowing down. Time zero is the impact, as the file declares it. One g is 9.81 m/s². The filter starts from zero at each end of the record. There are 50 ms of record before impact, so that start probably has no effect on the peak, although I have not checked it.

Program. a4_crossmember_peak.py (attached) finds the crossmember channel, checks that the filter passes a constant unchanged (it returns 1.000000), filters the channel, prints the peak and the other three numbers above, and draws the figure.

What to notice

The answer and the class are in the first two sentences, and the sentence Alice asked for follows them. The list gives the numbers a customer could get by working differently, so Alice can probably recognize a mismatch. The one condition that would change the answer (integrating the channel) comes with its own value.

A Technical Report

Example 2 · Technical report

Data phrase: example pack (test 9793)

Summary

The peak longitudinal acceleration of the left rear seat crossmember in test 9793, filtered at CFC 60 as SAE J211-1 requires for vehicle structure compared between vehicles, is −437.0 m/s² (−44.56 g) at 55.10 ms after impact. The proposed sentence for the customer is:

"Test 9793, left rear seat crossmember X acceleration (10SEATLERE00ACXP): peak −437.0 m/s² at 55.10 ms after impact, SAE J211-1 CFC 60, filtered forward and backward with no offset removed."

A different class, and so a different value, would be right if the customer integrates the channel to velocity or displacement. J211-1 gives that use CFC 180 (−509.6 m/s²).

Data

The channel is the one whose header names the crossmember. Its code is 10SEATLERE00ACXP, its location is "Seat" and its direction is "Longitudinal", and the values are in m/s². It holds 7001 samples at 20,000 samples per second, from −50 to 300 ms. The header also gives a prefilter of 4000 Hz, which is the analog filter the logger applied before sampling, so the unfiltered record has already been filtered once. The test speed is 56.15 km/h (15.60 m/s).

Method

A Python program, a4_filter_report.py (listed in the appendix and submitted with this report), does every calculation and draws every figure. It uses the J211-1 filter as given in the course notes. Each output sample is a weighted sum of the current and two previous inputs and the two previous outputs, with five coefficients fixed by the class and the sample spacing. The program runs this once forward and then once backward over the result, which cancels the delay a single pass causes. The peak is the sample with the largest absolute value. One g is taken as standard gravity, 9.80665 m/s².

The course standards page gives two classes for a vehicle structural acceleration, both from J211-1 Table 1: CFC 60 for a structural peak for comparing vehicles, and CFC 180 for integrating to velocity or displacement. The quantity here is a peak, not an integral, so this report uses CFC 60.

Results

Figure 1 shows the whole record. The filtered trace is a single smooth dip, and its largest value is −437.0 m/s² at 55.10 ms. The table gives the peak at every class J211 defines. Change in velocity (Δv, the area under the acceleration over the whole record) is included as a comparison.

FilterPeak (m/s²)Peak (g)At (ms)Δv (m/s)
Unfiltered (as recorded)−1919.8−195.852.75−17.429
CFC 1000−1243.1−126.852.75−17.429
CFC 600−995.2−101.552.75−17.429
CFC 180−509.6−52.053.35−17.430

The peak falls by a factor of 4.4 from the unfiltered record to CFC 60, while Δv changes only in the third decimal place (−17.429 to −17.435 m/s). That is what the course notes predict. A filter takes the top off a narrow spike and spreads it into the shoulders, so the area survives and the maximum does not. The peak also moves later, from 52.75 to 55.10 ms. This is not a delay from the filter, since the two passes cancel any delay. At CFC 180 and CFC 60 the narrow spike has been removed and a broader part of the pulse has become the largest value. Figure 2 shows this for the main pulse.

Checks

  • The filter passes a constant. A low-pass filter must return a constant unchanged. The gain on a constant is 1.000000000000 at all four classes.
  • The sample rate is high enough. The filter cannot be built unless the sample rate is above 4.155 times the class. For CFC 60 that is 249 samples per second, and the record has 20,000.
  • How the filter starts. Starting each pass from the first sample instead of from zero gives −437.02 m/s² at 55.10 ms, the same to two decimals.
  • Offset. The mean before impact is 0.041 m/s². Removing it before filtering gives −437.06 m/s². The customer will probably filter the file as it is, so the sentence uses the value with no offset removed and says so.
  • One pass against two. Run forward only, the filter gives −442.16 m/s² at 56.75 ms, 1.65 ms late (Figure 3). A customer who reports a later and slightly larger peak has probably filtered once.
  • Which g. The peak is −44.564 g with standard gravity and −44.548 g with 9.81 m/s². Those round to 44.6 and 44.5, so a value quoted to one decimal in g could come back different for this reason alone. The sentence therefore gives m/s², the unit of the file.

Errors and Anomalies

A very narrow unfiltered peak. The unfiltered channel reaches −1919.8 m/s² at 52.75 ms, and it is above half that value for only three samples (52.70 to 52.80 ms). It follows +1382.6 m/s² at 52.35 ms, 0.4 ms earlier. A swing that fast is probably ringing of the structure or the sensor mount, although I have not checked that. It is kept in the data, and it is the reason the filter class matters so much here.

The channel key. The key in the file is vehicle_x, but the header describes a sensor on the left rear seat crossmember. This report uses the header's description and code.

Assumptions

  • The customer is comparing vehicle structure, so CFC 60 applies.
  • The peak is the largest absolute value. It is negative because positive X points forward and the car is slowing down.
  • Time zero is the impact, as the file declares.

Appendix. Program

"""Assignment 4: peak crossmember acceleration filtered to SAE J211-1.

Run this from the unzipped pack folder. It finds the crossmember channel,
checks the filter, filters the channel at every class J211 defines, and prints
the numbers in the report. It saves three figures:
  fig_raw.svg      the whole record, as recorded and at CFC 60
  fig_classes.svg  the main pulse at each filter class
  fig_onepass.svg  CFC 60 run once and run forward and backward
"""
import json
import os

import matplotlib.pyplot as plt
import numpy as np

G = 9.80665          # standard gravity, m/s^2
CLASSES = [1000, 600, 180, 60]
PACK = '.'


def cfc_coefficients(cls, dt):
    """SAE J211-1 coefficients, as given in the course notes (Smoothing)."""
    wd = 2 * np.pi * cls * 2.0775
    wa = np.tan(wd * dt / 2)
    d = 1 + np.sqrt(2) * wa + wa ** 2
    a0 = wa ** 2 / d
    b1 = -2 * (wa ** 2 - 1) / d
    b2 = (-1 + np.sqrt(2) * wa - wa ** 2) / d
    return a0, 2 * a0, a0, b1, b2


def one_pass(x, c, start=0.0):
    """One pass in the direction of increasing index. start is what the two
    outputs before the first sample are taken to be."""
    a0, a1, a2, b1, b2 = c
    out = np.zeros(len(x))
    out[0] = out[1] = start
    for i in range(2, len(x)):
        out[i] = (a0 * x[i] + a1 * x[i - 1] + a2 * x[i - 2]
                  + b1 * out[i - 1] + b2 * out[i - 2])
    return out


def cfc(y, dt, cls, start_at_data=False):
    """Forward, then backward over the forward result. With start_at_data the
    filter starts from the first sample instead of from zero."""
    c = cfc_coefficients(cls, dt)
    fwd = one_pass(y, c, y[0] if start_at_data else 0.0)[::-1]
    return one_pass(fwd, c, fwd[0] if start_at_data else 0.0)[::-1]


def peak(t, y):
    i = int(np.argmax(np.abs(y)))
    return y[i], t[i]


name = os.listdir(os.path.join(PACK, 'crash'))[0]
with open(os.path.join(PACK, 'crash', name)) as f:
    test = json.load(f)

key = [k for k, ch in test['channels'].items() if 'CROSSMEMBER' in ch['comment']][0]
ch = test['channels'][key]
dt = ch['dt']
t = 1000 * (ch['t0'] + dt * np.arange(ch['n']))      # ms
raw = np.array(ch['y'])
print(f"channel '{key}': {ch['comment']} [{ch['code']}]")
print(f"  {ch['location']}, {ch['direction']}, {ch['unit']}, status {ch['status']}, "
      f"prefilter {ch['prefilter_hz']} Hz")
print(f"  {ch['n']} samples, {1 / dt:.0f} samples/s, {t[0]:.0f} to {t[-1]:.0f} ms")
print(f"  test speed {test['test']['speed_kph']} km/h = {test['test']['speed_kph'] / 3.6:.2f} m/s")

# how wide is the unfiltered peak? count the samples around it above half its size
i = int(np.argmax(np.abs(raw)))
lo, hi = i, i
while abs(raw[lo - 1]) > abs(raw[i]) / 2:
    lo -= 1
while abs(raw[hi + 1]) > abs(raw[i]) / 2:
    hi += 1
print(f"  unfiltered peak {raw[i]:.1f} m/s^2 at {t[i]:.2f} ms, above half that from "
      f"{t[lo]:.2f} to {t[hi]:.2f} ms ({hi - lo + 1} samples)")
j = int(np.argmax(raw[(t > 45) & (t < 60)])) + int(np.argmax(t > 45))
print(f"  largest positive value between 45 and 60 ms: {raw[j]:.1f} m/s^2 at {t[j]:.2f} ms")

print("\nchecks")
for cls in CLASSES:
    a0, a1, a2, b1, b2 = cfc_coefficients(cls, dt)
    print(f"  CFC {cls:4}: gain on a constant {(a0 + a1 + a2) / (1 - b1 - b2):.12f}, "
          f"needs more than {4.155 * cls:.0f} samples/s")
y60 = cfc(raw, dt, 60)
p60, tp60 = peak(t, y60)
p, tp = peak(t, cfc(raw, dt, 60, start_at_data=True))
print(f"  start from first sample instead of zero: {p:.2f} m/s^2 at {tp:.2f} ms")
offset = raw[t < 0].mean()
p, tp = peak(t, cfc(raw - offset, dt, 60))
print(f"  pre-impact mean {offset:.3f} m/s^2 removed first: {p:.2f} m/s^2 at {tp:.2f} ms")
print(f"  in g: {p60 / G:.3f} with g = {G}, {p60 / 9.81:.3f} with g = 9.81")

print("\nresult at CFC 60, forward and backward")
print(f"  peak {p60:.2f} m/s^2 = {p60 / G:.2f} g at {tp60:.2f} ms")
print(f"  the unfiltered peak is {raw.min() / p60:.2f} times this")

print("\nevery class")
print(f"  {'filter':12} {'peak m/s^2':>11} {'peak g':>8} {'at ms':>7} {'delta-v m/s':>12}")
filtered = {'as recorded': raw}
for cls in CLASSES:
    filtered[f'CFC {cls}'] = cfc(raw, dt, cls)
for label, y in filtered.items():
    p, tp = peak(t, y)
    dv = np.sum((y[1:] + y[:-1]) / 2) * dt        # trapezoid rule, whole record
    print(f"  {label:12} {p:11.1f} {p / G:8.1f} {tp:7.2f} {dv:12.3f}")

one = one_pass(raw, cfc_coefficients(60, dt))
p1, tp1 = peak(t, one)
print(f"\nCFC 60 forward pass only: {p1:.2f} m/s^2 = {p1 / G:.2f} g at {tp1:.2f} ms "
      f"({tp1 - tp60:+.2f} ms)")

# Figure 1: the whole record
plt.figure(figsize=(8, 3.6))
plt.plot(t, raw / G, color='lightgray', linewidth=0.7, label='as recorded')
plt.plot(t, y60 / G, linewidth=1.4, label='CFC 60, forward and backward')
plt.plot(tp60, p60 / G, 'ko', markersize=4)
plt.annotate(f"{p60 / G:.1f} g at {tp60:.1f} ms", (tp60, p60 / G), xytext=(12, -6),
             textcoords='offset points', fontsize=8)
plt.xlabel('time from impact (ms)')
plt.ylabel('X acceleration (g)')
plt.title(f"Left rear seat crossmember [{ch['code']}], test {test['testNo']}", fontsize=10)
plt.legend(loc='lower right', fontsize=8)
plt.tight_layout()
plt.savefig('fig_raw.svg')
plt.close()

# Figure 2: the main pulse at every class
plt.figure(figsize=(8, 3.6))
for label, y in filtered.items():
    if label == 'as recorded':
        plt.plot(t, y / G, color='lightgray', linewidth=0.7, label=label)
    else:
        plt.plot(t, y / G, linewidth=1.1, label=label)
plt.xlim(40, 80)
plt.xlabel('time from impact (ms)')
plt.ylabel('X acceleration (g)')
plt.title('Crossmember X acceleration at each J211 filter class, 40 to 80 ms', fontsize=10)
plt.legend(loc='lower right', fontsize=8)
plt.tight_layout()
plt.savefig('fig_classes.svg')
plt.close()

# Figure 3: one pass against two
plt.figure(figsize=(8, 3.6))
plt.plot(t, raw / G, color='lightgray', linewidth=0.7, label='as recorded')
plt.plot(t, one / G, linewidth=1.2, label='CFC 60, forward pass only')
plt.plot(t, y60 / G, linewidth=1.2, label='CFC 60, forward and backward')
plt.axvline(tp60, color='tab:orange', linestyle=':', linewidth=0.8)
plt.axvline(tp1, color='tab:blue', linestyle=':', linewidth=0.8)
plt.xlim(30, 90)
plt.ylim(-80, 30)
plt.xlabel('time from impact (ms)')
plt.ylabel('X acceleration (g)')
plt.title(f"CFC 60 run once peaks {tp1 - tp60:.2f} ms late (dotted lines mark the peaks)",
          fontsize=10)
plt.legend(loc='lower right', fontsize=8)
plt.tight_layout()
plt.savefig('fig_onepass.svg')
plt.close()

import numpy as np

# copied from the Smoothing notes
def cfc(y, dt, cls):
    wd = 2 * np.pi * cls * 2.0775
    wa = np.tan(wd * dt / 2)
    d  = 1 + np.sqrt(2) * wa + wa**2
    a0 = wa**2 / d;  a1 = 2 * a0;  a2 = a0
    b1 = -2 * (wa**2 - 1) / d
    b2 = (-1 + np.sqrt(2) * wa - wa**2) / d

    def one_pass(x):
        out = np.zeros_like(x)
        for i in range(2, len(x)):
            out[i] = (a0*x[i] + a1*x[i-1] + a2*x[i-2]
                      + b1*out[i-1] + b2*out[i-2])
        return out

    return one_pass(one_pass(y)[::-1])[::-1]

# check: a constant has to come out unchanged
print(cfc(np.ones(2000), cm['dt'], 60)[1000])
1.0000000000006188

That is 1 to about twelve decimal places, so the coefficients are probably right. Now the class.
