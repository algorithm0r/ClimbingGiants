Filtering a crash record to SAE J211

A frontal crash test is written down in three standards and a rating program.

ISO/TS 13499The data file International Organization for Standardization, Technical Specification 13499. It is one file format for impact-test data.
SAE J211-1Measuring and filtering SAE International (originally the Society of Automotive Engineers), ground-vehicle (J) standard 211, part 1.
FMVSS 208Protecting the occupants Federal Motor Vehicle Safety Standard 208. The 200 series covers protection in a crash.
NCAPThe star ratings New Car Assessment Program, the US government’s star ratings. Its frontal test is a rigid barrier at 35 mph (15.65 m/s).

FMVSS 208 requires a phaseless filter, such as J211’s, on every injury channel.

A phaseless filter adds no delay. It still smooths, so a sharp peak can come out lower.

FMVSS 208A federal rule It sets the crash tests and the injury limits for the dummies.
section S4.13A phaseless filter for injury data Channels used in injury calculations must be filtered with “a phaseless digital filter”, such as J211’s forward-backward filter.
our crossmemberA recommended class It is not an injury channel, so no rule sets its filter. J211’s Table 1 recommends a filter class (next slide) for each use.

J211 gives us the classes, the filter, and how to run it.

Table 1CFC 60, 180, 600, 1000 Each number is in hertz. Slower content passes nearly whole, and much faster content is cut. One class is recommended for each measurement.
Appendix CA Butterworth low-pass Its gain has no ripple below the class, so slow content keeps nearly its true size. One pass has five coefficients.
Appendix CForward, then backward Two passes, so the result is not shifted in time, and it cuts twice as steeply (four poles).

The narrower a feature, the faster the wiggles needed to make it.

a rough guideAbout $w$ wide, little above $1/w$ A feature about $w$ wide needs wiggles up to about $1/w$ a second, and little faster.
the whole carAbout 65 ms 95% of Δv is done by 65 ms. That needs content up to about 15 Hz, inside CFC 60.
the impact spikeAbout 0.45 ms wide Content up to about 2,200 Hz, though most of it is well below that. CFC 600 keeps most of its peak (1,284 of 1,540), and CFC 60 cuts it.

Computational Physical Modeling

The standard’s filter

Each class keeps content below its number and cuts content well above it.

Amplitude kept by each class, run forward and backward, at 12,500 samples a second.

Each output carries on the trend of the last two outputs, nudged by the newest inputs.

Class 60 at 12,500 samples a second, rounded (full values next).

$$y_i \;=\; a_0 x_i + a_1 x_{i-1} + a_2 x_{i-2} \;+\; \textcolor{#8A6508}{b_1 y_{i-1} + b_2 y_{i-2}}$$ $$y_i \;=\; 0.00094\,x_i + 0.00188\,x_{i-1} + 0.00094\,x_{i-2} \;+\; \textcolor{#8A6508}{1.91145\,y_{i-1} - 0.91520\,y_{i-2}}$$

The five numbers come from the class and the sample interval.

J211’s Appendix C formulas. Only CFC and $T$, in colour, change them.

$$\omega_d = 2\pi \cdot \textcolor{#8A6508}{\mathrm{CFC}} \cdot 2.0775 \qquad \omega_a = \tan\frac{\omega_d \textcolor{#8A6508}{T}}{2} \qquad D = 1 + \sqrt{2}\,\omega_a + \omega_a^2$$ $$a_0 = a_2 = \frac{\omega_a^2}{D} \qquad a_1 = 2a_0 \qquad b_1 = \frac{-2(\omega_a^2 - 1)}{D} \qquad b_2 = \frac{-1 + \sqrt{2}\,\omega_a - \omega_a^2}{D}$$ $$\textcolor{#8A6508}{\text{CFC} = 60,\ T = 0.00008\text{ s}}: \qquad a_0 = a_2 = 0.00093952 \qquad a_1 = 0.00187904$$ $$b_1 = 1.91144542 \qquad b_2 = -0.91520351$$

A low-pass filter must pass a constant unchanged.

A test for your implementation. A sign error still gives a smooth, plausible curve.

$$\begin{aligned} y &= a_0 c + a_1 c + a_2 c + b_1 y + b_2 y && \text{every input } c\text{, every settled output } y \\[10pt] y\,(1 - b_1 - b_2) &= (a_0 + a_1 + a_2)\,c && \text{gather the } y \text{ terms}\\[10pt] \frac{y}{c} &= \frac{a_0 + a_1 + a_2}{1 - b_1 - b_2} = \textcolor{#8A6508}{1} && \text{a constant passes unchanged} \end{aligned}$$

J211’s phaseless filter is one pass forward and one backward, which removes the delay.
