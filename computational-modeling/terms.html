Every term

These are all the terms the course's pages mark, with their definitions and the page that teaches each one. A term with no such page is background the course uses without teaching it, and its entry links the pages it appears on. Hovering over a marked term on any page shows the same definition.

Python

argument
A value passed into a function when it is called, such as the samples in peak(ch['y']). Taught on Functions.
array
A block of numbers under one name on which arithmetic applies to every value at once, so y / 9.81 divides every sample. numpy provides them in Python, and every MATLAB variable is one. Taught on numpy arrays.
assignment
The statement name = value. The right side is worked out first, and the result is stored under the name on the left. Taught on Names and assignment.
condition
An expression that is either true or false, such as y[i] < -100. An if statement runs its block only when its condition is true. Taught on Conditions.
dictionary
A collection of values in Python, each stored under its own key, written in braces. A JSON object loads into Python as a dictionary. Taught on Dictionaries and the data file.
f-string
A Python string with an f before the opening quote. Each expression inside braces in it is replaced by its value, and a format after a colon, as in {x:.2f}, sets how the number is written. Taught on Numbers and text.
floating-point number
A number stored with a fractional part, such as 56.34 or 8e-05, to about 16 significant digits. Python calls the type float, and MATLAB stores every number this way by default (as a double). Taught on Numbers and text.
function
A named block of code that takes inputs and hands back a result. Its body runs each time it is called, and the names inside it exist only while it runs. Taught on Functions.
generator expression
A comprehension in round brackets, usually written inside a call such as max, sum or next, which takes its values one at a time without storing them as a list. Taught on Comprehensions.
index
The position of a value in a sequence. Python counts positions from 0, so y[0] is the first value, and MATLAB counts from 1, so y(1) is. Taught on Lists, indexes and slices.
integer
A whole number, such as 4501 or 2019. Python calls the type int. Taught on Numbers and text.
JSON
A plain-text format for nested objects (labeled values) and arrays (ordered values). Every file in the data pack is JSON. Taught on Dictionaries and the data file.
key
The label a dictionary stores a value under, such as 'unit' or 'head_x'. The value is reached by writing the key in square brackets after the dictionary's name. Taught on Dictionaries and the data file.
keyword argument
An argument set by its name in the call, as in linewidth=0.8. Library functions use them for options. Taught on Functions.
list
An ordered sequence of values under one name, written in square brackets. Each value is reached by its position in the sequence. Taught on Lists, indexes and slices.
list comprehension
A list built in one line from a loop written inside square brackets, as in [v / 9.81 for v in y]. An if at the end keeps only the values that pass it. Taught on Comprehensions.
module
A file of functions that a program brings in with import, such as json, os or numpy. Taught on Files and libraries.
slice
A run of values taken from a sequence by a start, a stop and a step, as in y[1:3] or y[::2]. Python leaves out the value at the stop position, and MATLAB's y(2:3) includes it. Taught on Lists, indexes and slices.
string
A piece of text in a program, written between quotes, such as 'BMW' or 'm/(s*s)'. Taught on Numbers and text.
struct
MATLAB's collection of named fields, each reached with a dot, as in ch.unit. jsondecode turns a JSON object into a struct. Taught on Dictionaries and the data file.
traceback
The report Python prints when a program stops with an error: the route of calls that led to the failing line, then the kind of error and a message on the last line. Taught on Reading an error.
variable
A name in a program together with the value stored under it. The value can be replaced later by assigning to the same name again. Taught on Names and assignment.
working directory
The folder a program is running in. A relative path such as 'crash/10642.json' is looked up starting from it. Taught on Files and libraries.

Programs

branch
A point where a condition selects which of two paths executes. In numerical code the condition is usually a comparison against a tolerance or a bound. Taught on Program shape II, branching and encapsulation.
encapsulation
Naming a block of computation and fixing what crosses its boundary: declared inputs in, a returned value out, and nothing else either way. Taught on Program shape II, branching and encapsulation.
flow
The order in which a program's steps execute: straight through, repeated by a loop, or selected by a branch. Taught on Program shape I, state and flow.
literal
A value written directly into the source code rather than reached through a name, as 1e-6 and 0.5 are. Contrast a constant, which is a name whose value is fixed for the run. Taught on Program shape II, branching and encapsulation.
loop
A block of code executed repeatedly. What carries from one pass to the next is the loop's state; everything else is rebuilt each time. Taught on Program shape I, state and flow.
magic number
A literal sitting inside an expression with nothing to say what it means or where it came from. It cannot be questioned by a reader and cannot be found reliably when it has to change. Taught on Program shape II, branching and encapsulation.
state
The set of named values that exist at a given point in a program's execution. A single number and an array of a million are both state. Taught on Program shape I, state and flow.

Measurement

accelerometer
A sensor reporting the acceleration of the point it is bolted to. It measures the motion of its own mounting point, which is not always the motion of the object as a whole. Used on Bias and noise accumulate at different rates.
aliasing
A feature oscillating faster than half the sample rate appearing in the record as a slower one. It cannot be undone after sampling, which is why records are filtered before being sampled. Used on Discrete evaluation and resolution.
anti-alias filter
A low-pass filter applied to a signal before it is sampled, removing content too fast for the sample rate to represent. It has to act before sampling, because after sampling the aliased content is no longer separable from the rest. Taught on Discrete evaluation and resolution.
baseline
The value a signal takes when the quantity it measures is zero. Estimating it from a stretch of record where nothing is happening and subtracting it is called baseline correction. Taught on Bias and noise accumulate at different rates.
CFC class
The channel frequency class in SAE J211, a number naming the frequency response a data channel has: for CFC 60 and 180 the response of the filter in Appendix C, and for CFC 600 and 1000 a response within the limits of the standard's Figure 1. Table 1 recommends a class for each measurement, such as CFC 1000 for head acceleration and CFC 180 for a vehicle acceleration that will be integrated to velocity. Taught on The filter class is part of the measurement.
channel
One recorded signal within a test: a single sensor on a single axis, with its own units, sample rate, and identifying code. Taught on Anatomy of a measured signal.
channel code
The positional string in a channel's header identifying what was measured and where, such as 11HEADCG0000ACXP for a driver head acceleration. It identifies the measurement wherever the channel happens to sit in the file. Taught on Anatomy of a measured signal.
data status
The header field carrying the laboratory's own verdict on whether a channel is usable. A channel can be full of numbers and still be marked as something other than ok. Taught on Anatomy of a measured signal.
frequency
How many times something repeats per unit time, measured in hertz (Hz), where one hertz is once per second. A sample rate is a frequency; so is the rate at which a quantity oscillates. Taught on Discrete evaluation and resolution.
Nyquist frequency
Half the sample rate. It is the fastest oscillation a record at that rate can represent; anything faster is recorded as something slower, which is aliasing. Taught on Discrete evaluation and resolution.
pulse
The acceleration record of a vehicle through an impact, so called because it is one brief excursion: near zero before contact, tens of g for a few tens of milliseconds, near zero again. The envelope has that shape, while the signal inside it oscillates as the structure folds. Used on Smoothing and phase lag.
resultant
The magnitude of a vector quantity measured on three perpendicular axes: the square root of the sum of the squared components. It has no direction and is never negative. Used on A constrained optimum over a window.
sample rate
How many measurements are recorded per second, in hertz. Its reciprocal is the spacing Δt between consecutive samples. Taught on Anatomy of a measured signal.
time series
A sequence of values indexed by time. Every channel in a crash record is one: the values are stored in order, and the instant each belongs to comes from the time of the first sample and the sampling interval. Taught on Anatomy of a measured signal.

Crash tests

change in velocity
The total change in a body's velocity over an event, written Δv. For a crash it is the approach speed plus any rebound speed, and it is the standard measure of severity. Used on The constant of integration.
crossmember
A structural beam running across the vehicle floor between the side rails. Instruments are often mounted on one because it is stiff and close to the occupants. Used on Bias and noise accumulate at different rates.
crush
How far the front of a vehicle deforms during an impact, measured from first contact to the moment it stops moving forward, and found by integrating an acceleration record twice. Also called dynamic crush, which separates it from the smaller permanent deformation left once the structure springs back. Used on Assignment 3 · Impact Speed and Crush Distance.
FMVSS 208
The United States federal motor vehicle safety standard for occupant crash protection. It sets the injury assessment reference values a vehicle must meet, including HIC15 of 700. Used on A constrained optimum over a window.
Head Injury Criterion
A number computed from a head acceleration record, defined as the largest value a particular weighted average attains over any window no longer than a stated limit. Written HIC15 or HIC36 for the 15 ms and 36 ms limits. Taught on A constrained optimum over a window.
longitudinal
Along the vehicle's fore-and-aft axis. The other two vehicle axes are lateral, across the vehicle, and vertical. Used on Anatomy of a measured signal, Bias and noise accumulate at different rates.
rigid barrier
A fixed, non-deforming concrete block used as the impact surface, so that essentially all of the deformation happens in the vehicle. Used on Bias and noise accumulate at different rates.

Standards

phase lag
The shift in time a filter introduces. A filter applied once delays events; applied forward and then backward, the two shifts cancel and it delays nothing. Taught on Smoothing and phase lag.
zero-phase filtering
Running the same filter over a record twice, once forwards and once backwards, so the two equal and opposite time shifts cancel exactly. It buys that cancellation with a filter that uses the future, which a real-time filter cannot do. Taught on Smoothing and phase lag.

Mechanics

bending moment
The internal moment carried by a beam at a cross-section, equal to the moment about that section of all loads and reactions to one side of it. Used on Root-finding failures.
coefficient of restitution
The ratio of separation speed to approach speed in an impact. Zero means the bodies stay together; one means no kinetic energy is lost. Used on Bias and noise accumulate at different rates.
conserved quantity
Something the physics fixes: energy, momentum, mass. Its known behavior makes it a check on an integrator that needs no exact solution to compare against. Taught on Stability and accuracy.
deflection
The transverse displacement of a beam from its unloaded position, measured perpendicular to its axis. Used on Root-finding failures.
point of contraflexure
A point along a beam where the bending moment passes through zero and the curvature reverses. Beams with an overhang have one between the supports. Used on Root-finding failures.
resonance
The large response a lightly damped structure gives when it is driven near its natural frequency. The peak is narrow in frequency, which is what makes it easy for a coarse sweep to miss. Taught on Discrete evaluation and resolution.
simply supported
A beam resting on two supports that carry vertical force but apply no moment, so the bending moment is zero at each support. Used on Root-finding failures.
uniformly distributed load
A load spread evenly along a beam, quoted as force per unit length. Written w, in N/m or kN/m. Used on Root-finding failures.

Units

standard gravity
The conventional acceleration 9.80665 m/s², written g. Accelerations are often quoted as multiples of it. Used on Bias and noise accumulate at different rates, A constrained optimum over a window.

Numerical methods

bisection
A root-finding method that keeps an interval whose ends give f opposite signs, and halves it each step. It cannot start without such an interval, and it cannot fail once it has one. Taught on Bisection.
bracket
An interval whose two ends give f values of opposite sign. If f is continuous, a root lies somewhere inside it. Taught on Bisection.
cancellation
The loss of significant figures when two nearly equal computed numbers are subtracted. The result keeps its digits; most of them stop meaning anything. Taught on Solving the normal equations.
central difference
Estimating a derivative from the samples either side of a point: (f(x+h) − f(x−h)) / 2h. Its truncation error is proportional to h². Taught on Finite differences.
concave
Bending downward, so that a chord joining two points on the curve lies below the curve between them. A function is concave wherever its second derivative is negative. Taught on Area under a curve.
constant of integration
The additive constant an integral does not determine. Integration fixes the shape of the curve; an initial condition fixes where it sits. Taught on The constant of integration.
convergence study
Halving a step or refining a grid until the answer stops moving, as a way of defending a resolution when no exact answer is available. Taught on Order of accuracy.
convex
Bending upward, so that a chord joining two points on the curve lies above the curve between them. A function is convex wherever its second derivative is positive. Taught on Area under a curve.
cumulative integral
The running total of an integral: an output value for every input sample, each holding the area accumulated up to that point. Taught on Cumulative integration.
decimation
Keeping every k-th sample of a record and discarding the rest, reducing the sample rate by the factor k. Taught on Discrete evaluation and resolution.
definite integral
The signed area between a curve and the axis over a stated interval. One number, not a curve. Taught on Area under a curve.
double root
A root where f touches zero without crossing it, so f has the same sign on both sides. No bracket containing it exists. Taught on Root-finding failures.
error
The gap between a model and the truth. It can be evaluated only where the truth is known, and fitting has not minimized it. Taught on Residual and error.
Euler's method
The simplest stepping rule: advance the state by the step times the rate found at the start of the step. First order, and the cumulative integral of week 3 with the integrand recomputed each step. Taught on Euler's method.
evaluation budget
The number of times a method may compute f. The unit that matters whenever f is expensive, and the one that makes methods with different per-iteration costs comparable. Taught on Evaluation cost.
extrapolation
Evaluating a fitted model outside the range of the data used to fit it. Parameter uncertainty is multiplied by the distance beyond that range. Taught on Extrapolation and uncertainty.
fit error
Error measured on the data the model was fitted to. Adding parameters always reduces it. Taught on Fit error and prediction error.
forward difference
Estimating a derivative from a point and the one after it: (f(x+h) − f(x)) / h. Its truncation error is proportional to h. Taught on Finite differences.
held-out data
Data kept out of the fit and used afterwards to measure prediction error. The only direct way to find out how a model does on something it was not fitted to. Taught on Fit error and prediction error.
initial condition
A known value of the integrated quantity at one instant, which supplies the constant of integration. Taught on The constant of integration.
interpolation
Constructing a curve that passes through every data point. Appropriate when the values are exact, and a way of following the noise when they are not. Taught on Interpolation and regression.
least squares
Choosing model parameters to minimize the sum of squared residuals. One convention among several: it is the choice that minimizes the 2-norm of the residual vector. Taught on Least squares and the choice of norm.
linear in the parameters
A model in which each unknown appears only multiplied by a function of the independent variable and added to the others. It is this, not the shape of the curve, that gives least squares a closed-form solution. Taught on Linearity in the parameters.
machine epsilon
The gap between 1 and the next number the machine can store. About 2.2×10⁻¹⁶ in double precision, which is where a double's roughly sixteen significant digits come from. Taught on Solving the normal equations.
model form
The shape of a model — a line, a parabola, a decaying exponential — chosen before fitting. Fitting adjusts the parameters within a form; it cannot change the form. Taught on Model form and free parameters.
moving average
Replacing each sample by the mean of a window of samples around it. The simplest smoothing filter, and the one whose cost is easiest to state. Taught on Smoothing and phase lag.
Newton's method
A root-finding method that follows the tangent at the current estimate down to the axis and takes the crossing as the next estimate. It needs the derivative and keeps no interval. Taught on Newton and the secant method.
order of accuracy
The exponent p in error ∝ h^p, relating a method's error to its step size. It is measured by halving the step and taking the ratio of successive errors: a ratio of 2 is order 1, of 4 order 2, of 16 order 4. Taught on Order of accuracy.
order of convergence
The exponent p in e(k+1) ≈ C·e(k)^p. Bisection has p = 1, the secant method p ≈ 1.618, Newton p = 2 near a simple root. Taught on Newton and the secant method.
overfitting
Using enough free parameters that the model follows the noise in the data as well as the signal. The residual falls; the error against the truth rises. Taught on Model form and free parameters.
pole
A point where a function grows without bound because its denominator goes to zero. A function can change sign across a pole without having a root there. Taught on Root-finding failures.
prediction error
Error measured on data the model was not fitted to. Adding parameters reduces it only up to a point, after which it rises. Taught on Fit error and prediction error.
prefix sum
An array whose entry i holds the running total of the input up to i. Once built, the total over any range is the difference of two of its entries. Taught on A constrained optimum over a window.
regression
Fitting a model with fewer parameters than data points, so it cannot pass through them all. Its residuals are what is left of the noise it declined to follow. Taught on Interpolation and regression.
resampling
Estimating the spread of a result by perturbing the inputs within their known scatter, re-running the whole analysis, and collecting the distribution of answers. Taught on Propagating uncertainty by resampling.
residual
The value of f at an estimate: how far the equation is from being satisfied there. Distinct from the error, which is how far the estimate is from the true root. Taught on Residual and error.
residual structure
Pattern in the residuals — runs of the same sign, a trend, a shape — as opposed to random scatter. Structure says the model form is wrong, whatever the residuals' size. Taught on Residual structure.
RK4
The classical fourth-order Runge-Kutta method: four rate evaluations per step, combined so the errors of orders 1 through 4 cancel. Taught on Order of accuracy.
rounding error
The error introduced by storing numbers to finite precision. In a difference formula it does not shrink with the step, so dividing by the step magnifies it. Taught on Order of accuracy.
secant method
A root finder that replaces Newton's tangent with the line through the two most recent estimates. It needs no derivative and costs one evaluation per step. Taught on Newton and the secant method.
spline
A curve built from low-degree polynomials on each interval, joined smoothly. Interpolates without the oscillation a single high-degree polynomial suffers. Taught on Interpolation and regression.
stability
Whether a method's solution stays bounded. It fails abruptly past a threshold set by the step size and the system, and far past the step at which the answer stopped being accurate. Taught on Stability and accuracy.
stencil
The set of sample points a difference formula uses. A wider stencil can cancel more Taylor terms, or average away more noise, but reaches further from the point of interest. Taught on Finite differences.
sweep
Evaluating a quantity at a chosen set of input values and collecting the results, in order to see how one depends on the other. Taught on Discrete evaluation and resolution.
symplectic method
A stepping rule that preserves a structural property of the equations — for mechanics, that it does not manufacture energy — usually at the cost of accuracy. Taught on Stability and accuracy.
tolerance
The threshold a routine tests against to decide it has finished. Usually a bound on the size of f at the current estimate, which is not the same as a bound on the error in the estimate. Taught on Bisection.
trapezoid rule
Estimating the area under a curve by joining consecutive samples with straight lines and adding the areas of the trapezoids that result. Taught on Area under a curve.
truncation error
The error a finite-difference formula would have on a machine of infinite precision: the size of the Taylor terms the formula drops. It falls as the step falls. Taught on Finite differences.

Fitting

normal equations
The square linear system whose solution is the least-squares fit of a model linear in its parameters. Entry (i,j) is the sum over the data of the ith and jth model functions multiplied together. Taught on Solving the normal equations.

Linear algebra

condition number
How much a linear system amplifies error: the factor by which a small change in the matrix or the right-hand side can change the solution. About log10 of it is the number of significant digits lost, out of the sixteen a double carries. Taught on Solving the normal equations.
partial pivoting
Swapping the row with the largest entry in the current column to the top before eliminating with it. Costs one comparison per column and prevents division by a small pivot, which would otherwise cancel the leading digits of every row it touches. Taught on Solving the normal equations.

Statistics

bootstrap
Resampling the data itself, with replacement, to see how much a result depends on which particular measurements were taken. Taught on Propagating uncertainty by resampling.
confidence level
The proportion of repeated cases in which an interval is claimed to contain the true value. An interval quoted without one is not interpretable. Taught on Reporting an interval.
coverage
The proportion of repeated cases in which an interval actually does contain the true value. It is measured, where the confidence level is claimed. Taught on Coverage.
expected value
The average a quantity would take over indefinitely many repetitions of the same measurement. A random error with expected value zero is as likely to be positive as negative. Taught on Bias and noise accumulate at different rates.
Gaussian noise
Random error following the normal distribution, characterized entirely by its mean and standard deviation. Most measurement scatter is modeled this way. Used on Coverage.
standard deviation
A measure of how far values typically fall from their mean: the square root of the average squared distance from it. Used on Bias and noise accumulate at different rates, Differentiation amplifies noise.
