Drag makes the acceleration depend on the velocity, so no formula is known for the path.

The rate is how fast the state changes. r is the position (x, y, z), v the velocity, |v| the speed, and ẑ points up. Drag grows with the speed squared, with k = 0.016 per meter.

$$\frac{\mathrm{d}\mathbf{r}}{\mathrm{d}t} \;=\; \mathbf{v}, \qquad \frac{\mathrm{d}\mathbf{v}}{\mathrm{d}t} \;=\; -g\,\hat{\mathbf{z}} \;\textcolor{#8A6508}{-\; k\,|\mathbf{v}|\,\mathbf{v}}$$

Euler’s method adds the rate times the step to the current state.

si is the state at time ti, all six numbers, f is the rate from the last slide, and h is the step. The rate is read at the start of the step and held across it, as in the rectangle rule.

$$s_{i+1} \;=\; s_i \;+\; \textcolor{#8A6508}{h\, f(t_i,\, s_i)}$$

One 40 ms step takes the height from 4.2018 to 4.3118 m.

The velocity steps too, using the acceleration. The other components step the same way.

$$\begin{aligned} |\mathbf{v}| &= \sqrt{4.7333^2 + 3.9732^2 + 2.7508^2} = 6.76\ \text{m/s} \\[4pt] a_z &= -9.81 - 0.016 \times 6.76 \times 2.7508 = -9.81 - 0.298 = -10.108\ \text{m/s}^2 \\[4pt] z &= 4.2018 + 0.04 \times 2.7508 = \textcolor{#8A6508}{4.3118\ \text{m}} \\[4pt] v_z &= 2.7508 + 0.04 \times (-10.108) = 2.3465\ \text{m/s} \end{aligned}$$

The loop starts each step from the last step’s result.

18 steps of 40 ms reach frame 23.

def euler(f, s0, t0, dt, n):
f is the rate, dt the step, n the number of steps
s = np.array(s0, dtype=float)
the starting state
out = np.empty((n + 1, s.size))
one row per time
out[0] = s
for i in range(n):
s = s + dt * f(t0 + i*dt, s)
adds the step times the rate
out[i + 1] = s
return out

A straight step on a curve that bends down lands about 8 mm high.

The height is concave, bending downward. The step keeps vh and leaves out ½ah² of z₀ + vh + ½ah², and ½ × 10.108 × 0.04² = 8.1 mm.

Each step keeps the last one’s overshoot, so the gap grows about 8 mm a step.

The gap to the 0.1 ms run after each 40 ms step, in millimeters.

A velocity error made in one step moves every later height.

Each overshoot is measured from the 0.1 ms run’s state. The downward acceleration falls from 10.11 to 9.32 m/s² over the flight, and Euler uses each step’s starting value, which leaves the vertical velocity about 15 mm/s low by frame 23.
