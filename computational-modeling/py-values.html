Numbers and text

The values in a crash record come in three kinds. The number of samples is a whole number (4501), the samples and the sampling interval are numbers with a fractional part (−0.362869, 0.00008), and the channel code, the unit and the vehicle's make are text. Python keeps track of which kind each value is, and it prints and combines the three differently, so it is worth being able to tell them apart on sight. This page also covers the f‑string, which is how most programs on this site turn a number into a line of a report.

What It Looks Like

make = 'BMW'
year = 2019
speed_kph = 56.34
dt = 8e-05

print(type(year), type(speed_kph), type(make))
print(f'{year} {make} at {speed_kph} km/h')
print(f'{speed_kph / 3.6:.2f} m/s')
print(f'sample rate {1 / dt:.0f} Hz')
make = 'BMW';
year = 2019;
speed_kph = 56.34;
dt = 8e-05;

disp(class(year)), disp(class(make))
fprintf('%d %s at %g km/h\n', year, make, speed_kph);
fprintf('%.2f m/s\n', speed_kph / 3.6);
fprintf('sample rate %.0f Hz\n', 1 / dt);

The letter e in a number means "times ten to the power". So 8e-05 is 8 × 10−5, which is 0.00008, and it is the form Python uses to print very small and very large numbers. A number in quotes is text. That is, '2019' is four characters and 2019 is a number you can do arithmetic with (the data pack stores the vehicle's year as text, which you will see on Dictionaries).

Arithmetic

+, -, * and / do what you expect, and ** is a power, so v**2 is v squared (MATLAB writes it v^2). Division always gives a float in Python, so 4500 / 2 is 2250.0, and // is division that drops the remainder (4501 // 2 is 2250). A float is stored in binary to about 16 significant digits, and most decimal fractions (0.1, for instance) cannot be stored exactly, so a result can carry a tiny error in its last digit. For instance, 0.1 + 0.2 prints as 0.30000000000000004. Floats behave this way in every language, and it is why the programs on this site round a number when they print it (the next section) and compare two floats with a tolerance.

Putting Numbers in Text

An f‑string is a string with an f before the opening quote. Inside it, anything in braces is worked out and replaced by its value, so f'{year} {make}' becomes 2019 BMW. A colon inside the braces sets how a number is written, and the padded form lines numbers up in columns, which is why the example reports use it for their printed tables. These are the forms you will see on this site:

In the bracesMeans56.34 / 3.6 written this way
{x:.2f}two digits after the decimal point15.65
{x:.0f}no digits after the point, so rounded to a whole number16

{x:.3e}the times-ten-to-the-power form, three digits after the point1.565e+01

In MATLAB

MATLAB stores every number as a double (a float) unless you ask for another kind, which is why class(year) prints double. Text in single quotes is a character array, and that is what jsondecode gives you for every string in the data pack. MATLAB has no f‑string. fprintf and sprintf take a pattern with % slots and fill them from the values that follow, in order, so %.2f plays the part of :.2f. fprintf prints the result and sprintf returns it as text, which is the one you want for a plot title.

Check
  1. What does f'{4501 * 8e-05:.3f} s' give, and what does that number say about a channel?
    Answer

    0.360 s. It is about how long the channel recorded (the first and last of the 4501 samples are 4500 intervals apart, so the exact span is 0.3600 s).

  2. A header gives the unit as 'm/(s*s)'. Is that a number or text, and could you divide by it?
    Answer

    Text. It is in quotes, so it is a string of seven characters, and Python stops with an error if you try to divide by it. It is there to be read and printed.

  3. Why does print(0.1 + 0.2 == 0.3) print False?
    Answer

    A float holds about 16 significant digits, and neither 0.1 nor 0.2 can be stored exactly, so their sum is 0.30000000000000004. Two floats are compared with a tolerance, as in abs(a - b) < 1e-9, which Conditions covers.
