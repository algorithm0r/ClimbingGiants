Each simple rule is a short function that takes r and returns a frame.

def last_k(r, k=7):             # the last k frames
    return len(r["t"]) - k

def above(r, z0=3.048):         # the first frame above z0
    return np.argmax(r["z"] > z0)

def inside_line(r, i=1):        # i-th frame inside the line
    dx = r["x"] - r["hoop_x"]
    dy = r["y"] - r["hoop_y"]
    d = np.sqrt(dx**2 + dy**2)  # distance to the hoop center
    return np.argmax(d < 7.24) + i - 1

On record 158 these return frames 19, 17 and 16. np.argmax of an array of True and False returns the index of the first True, or 0 if none is True.

The complex rules first estimate a speed or an acceleration from the frames, then walk back from the end to where it changes.

def speed_peak(r, h=3):
    t, z = r["t"], r["z"]
    v = (z[2*h:] - z[:-2*h]) / (t[2*h:] - t[:-2*h])     # v[j] belongs to frame j + h
    j = len(v) - 1
    while j > 0 and v[j-1] > v[j]:
        j = j - 1
    return j + h

def near_gravity(r, h=3, tol=5):
    t, z = r["t"], r["z"]
    dt = t[1] - t[0]
    a = (z[2*h:] - 2*z[h:-h] + z[:-2*h]) / (h*dt)**2    # a[j] belongs to frame j + h
    j = len(a) - 1
    while j > 0 and abs(a[j-1] + 9.81) < tol:
        j = j - 1
    return j + h

Each needs a step h, and the gravity rule a tolerance as well. With h = 1, a second difference combines three heights, each off by about 3 cm. If those errors were independent, the acceleration would be off by about √6 × 3 cm / (0.04 s)² ≈ 46 m/s², nearly five times gravity.

On record 158 the six rules start the fit anywhere from frame 16 to frame 22.

Step 5 of 11 · When does the ball reach the rim?

$$\text{height} = -2.6434 + 11.8107\,t - 4.905\,t^2$$
$$\text{height} - 3.048 = -4.905\,t^2 + 11.8107\,t - 5.6914 = 0$$

The quadratic formula gives both roots, and the minus sign gives the later one, the falling crossing.

$$t = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} = \frac{-11.8107 \pm \sqrt{27.827}}{-9.81}$$
$$t = \frac{-11.8107 + 5.2752}{-9.81} = 0.666\ \text{s} \quad \text{rising}$$
$$t = \frac{-11.8107 - 5.2752}{-9.81} = \textcolor{#5F7038}{\mathbf{1.742\ s}} \quad \textcolor{#5F7038}{\textbf{falling}}$$

a is negative, so the minus sign gives the later time.

Step 8 of 11 · predict(r, s)

def predict(r, s):
    t, x, y, z = r["t"][s:], r["x"][s:], r["y"][s:], r["z"][s:]
    v, c0 = np.polyfit(t, z + 4.905*t**2, 1)    # z is the height; gravity held
    a, b, c = -4.905, v, c0 - 3.048
    tc = (-b - np.sqrt(b*b - 4*a*c)) / (2*a)    # the later root
    vx, x0 = np.polyfit(t, x, 1)
    vy, y0 = np.polyfit(t, y, 1)
    return tc, x0 + vx*tc, y0 + vy*tc

predict(r158, 17) returns 1.742 s at (26.815, 7.733). Step 3’s crossing(r, rule) is predict(r, rule(r)).
