Reading the assignment 9 program

This page reads a9_benchmark.py, the program behind the technical report in the assignment 9 example reports, one section at a time. The program puts the customer's car beside two others. It reads three crash tests, treats each one the same way (the three head channels filtered at CFC 1000, a resultant in g, then HIC15 and its window), prints what each header says about its test, and then places the customer's car among the three. Two checks follow, and two figures. Each section shows the Python beside a MATLAB version that prints the same results (checked by running both on the example pack, the MATLAB version in GNU Octave), and the line notes say what each line does.

The HIC search is the one from the assignment 6 program (Reading the assignment 6 program), written more compactly. Program shape I suggests reading unfamiliar code by finding what comes in, what goes out and the state each loop builds, and the next section starts there. In the Python file the functions come first and the main part follows, from the top down. A MATLAB script has to keep its functions at the end, so its line ranges jump. A line you cannot read is usually covered on one of the Reading Python pages, which the notes link to, and the MATLAB lines have notes of their own.

The Filter

The CFC filter is the one from Smoothing, copied in. J211 sets class 1000 for head acceleration. It runs forward over the record and then backward over the result, so the two passes' delays cancel.

def cfc(y, dt, cls):
    """SAE J211-1 filter class: 4-pole Butterworth, forward then backward."""
    wd = 2 * math.pi * cls * 2.0775
    wa = math.tan(wd * dt / 2)
    d = 1 + math.sqrt(2) * wa + wa ** 2
    a0 = wa ** 2 / d
    b1 = -2 * (wa ** 2 - 1) / d
    b2 = (-1 + math.sqrt(2) * wa - wa ** 2) / d

    def one_pass(x):
        out = np.zeros_like(x)
        for i in range(2, len(x)):
            out[i] = (a0 * x[i] + 2 * a0 * x[i - 1] + a0 * x[i - 2]
                      + b1 * out[i - 1] + b2 * out[i - 2])
        return out

    forward = one_pass(y)
    backward = one_pass(forward[::-1])
    return backward[::-1]
function out = cfc(y, dt, cls)
    % SAE J211-1 filter class: 4-pole Butterworth, forward then backward.
    wd = 2 * pi * cls * 2.0775;
    wa = tan(wd * dt / 2);
    d = 1 + sqrt(2) * wa + wa^2;
    a0 = wa^2 / d;
    b1 = -2 * (wa^2 - 1) / d;
    b2 = (-1 + sqrt(2) * wa - wa^2) / d;
    c = [a0, b1, b2];
    forward = one_pass(y, c);
    backward = one_pass(flip(forward), c);
    out = flip(backward);
end


function out = one_pass(x, c)
    a0 = c(1);
    b1 = c(2);
    b2 = c(3);
    out = zeros(size(x));
    for i = 3:numel(x)
        out(i) = a0 * x(i) + 2 * a0 * x(i-1) + a0 * x(i-2) ...
                 + b1 * out(i-1) + b2 * out(i-2);
    end
end

HIC

The search loops over window lengths up to the limit. For one length, a running total of the integral gives every window's integral by one subtraction, so all the starts are handled at once. The function keeps the best HIC found and the first and last sample of its window.

def hic(a_g, dt, limit_ms):
    """HIC over every window up to limit_ms. Returns (value, (first, last))."""
    panels = (a_g[1:] + a_g[:-1]) / 2 * dt
    S = np.concatenate([[0.0], np.cumsum(panels)])
    kmax = int(round(limit_ms / 1000 / dt))      # the limit in samples
    best = 0.0
    window = (0, 0)
    for k in range(1, kmax + 1):
        T = k * dt
        v = T * np.clip((S[k:] - S[:-k]) / T, 0, None) ** 2.5   # every start at once
        i = int(np.argmax(v))
        if v[i] > best:
            best = float(v[i])
            window = (i, i + k)
    return best, window
function [best, window] = hic(a_g, dt, limit_ms)
    % HIC over every window up to limit_ms. Returns the value and [first, last].
    panels = (a_g(2:end) + a_g(1:end-1)) / 2 * dt;
    S = [0; cumsum(panels)];
    kmax = round(limit_ms / 1000 / dt);       % the limit in samples
    best = 0;
    window = [1, 1];
    for k = 1:kmax
        T = k * dt;
        v = T * max((S(k+1:end) - S(1:end-k)) / T, 0).^2.5;   % every start at once
        [top, i] = max(v);
        if top > best
            best = top;
            window = [i, i + k];
        end
    end
end

The Resultant

The resultant filters each axis and then combines the three into one size, whatever the direction, in g. Passing no class skips the filter, which the second check uses.

def resultant(axes, dt, cls=1000):
    """Filter each axis (cls=None skips it), then the resultant in g."""
    if cls:
        filtered = []
        for a in axes:
            filtered.append(cfc(a, dt, cls))
        axes = filtered
    return np.sqrt(axes[0] ** 2 + axes[1] ** 2 + axes[2] ** 2) / G
function r = resultant(axes_g, dt, cls, G)
    % Filter each axis (an empty cls skips it), then the resultant in g.
    if ~isempty(cls)
        for m = 1:3
            axes_g{m} = cfc(axes_g{m}, dt, cls);
        end
    end
    r = sqrt(axes_g{1}.^2 + axes_g{2}.^2 + axes_g{3}.^2) / G;
end

Two Checks

The customer's car was recorded at 20,000 samples a second and the other two at 10,000. The first check keeps every second sample of the customer's car (every step-th, in general, to match the slowest other car) and recomputes, to see whether the sample rate explains any of the difference. The second recomputes every car with no filter at all.

Running It Yourself

Both versions are downloads: a9_benchmark.py and a9_benchmark.m. Unzip a data pack, put the program in the pack's top folder beside crash and shots, and run it from there (Files and libraries explains why the folder matters). In Colab, upload the program beside your unzipped pack and run it in a cell with %run a9_benchmark.py (the Colab guide shows how). On your own pack it reads your data, so its numbers will differ from the ones above. The MATLAB version should run as it is in MATLAB R2018b or later. GNU Octave, which is free, needs a script's functions defined before they are used, so to run it there, move the functions to the top of the file and put a line 1; above them. This program also needs the fleet folder beside crash, holding the two colleagues' tests.
