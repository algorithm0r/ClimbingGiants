Reading the assignment 6 program

This page reads a6_hic_search.py, the program behind the technical report in the assignment 6 example reports, one section at a time. The program finds the driver's HIC15. It filters the three head channels, combines them into one resultant in g, and searches every window up to 15 ms for the largest HIC. Then it counts what that search cost, because the report also has to say how long the method would take on 200 more tests. Each section shows the Python beside a MATLAB version that prints the same results (checked by running both on the example pack, the MATLAB version in GNU Octave), and the line notes say what each line does.

The search uses the idea from A constrained optimum over a window. A running total of the integral, built once, makes every window's integral a single subtraction. Program shape I suggests reading unfamiliar code by finding what comes in, what goes out and the state each loop builds, and the next section starts there. In the Python file the functions come first and the main part follows, from the top down. A MATLAB script has to keep its functions at the end, so its line ranges jump. A line you cannot read is usually covered on one of the Reading Python pages, which the notes link to, and the MATLAB lines have notes of their own.

The Filter

The CFC filter is the one from Smoothing, copied in, and J211 sets class 1000 for head acceleration. It runs forward over the record and then backward over the result, so the two passes' delays cancel.

def cfc(y, dt, cls):
    """SAE J211-1 Butterworth (Smoothing notes), run forward then backward."""
    wd = 2 * np.pi * cls * 2.0775
    wa = np.tan(wd * dt / 2)
    d = 1 + np.sqrt(2) * wa + wa**2
    a0 = wa**2 / d
    a1 = 2 * a0
    a2 = a0
    b1 = -2 * (wa**2 - 1) / d
    b2 = (-1 + np.sqrt(2) * wa - wa**2) / d

    def one_pass(x):
        out = np.zeros_like(x)
        for i in range(2, len(x)):
            out[i] = (a0 * x[i] + a1 * x[i - 1] + a2 * x[i - 2]
                      + b1 * out[i - 1] + b2 * out[i - 2])
        return out

    forward = one_pass(y)
    backward = one_pass(forward[::-1])
    return backward[::-1]
function out = cfc(y, dt, cls)
    % SAE J211-1 Butterworth (Smoothing notes), run forward then backward.
    wd = 2 * pi * cls * 2.0775;
    wa = tan(wd * dt / 2);
    d = 1 + sqrt(2) * wa + wa^2;
    a0 = wa^2 / d;
    a1 = 2 * a0;
    a2 = a0;
    b1 = -2 * (wa^2 - 1) / d;
    b2 = (-1 + sqrt(2) * wa - wa^2) / d;
    c = [a0, a1, a2, b1, b2];
    forward = one_pass(y, c);
    backward = one_pass(flip(forward), c);
    out = flip(backward);
end


function out = one_pass(x, c)
    out = zeros(size(x));
    for i = 3:numel(x)
        out(i) = c(1) * x(i) + c(2) * x(i - 1) + c(3) * x(i - 2) ...
                 + c(4) * out(i - 1) + c(5) * out(i - 2);
    end
end

The Resultant

The resultant is the size of the acceleration whatever its direction. It is the square root of the sum of the three components squared, converted to g. HIC is defined on the resultant in g, which is why the conversion happens here.

def resultant_g(comps):
    total = 0
    for c in comps:
        total = total + c**2
    return np.sqrt(total) / G
function r = resultant_g(comps, G)
    total = 0;
    for k = 1:numel(comps)
        total = total + comps{k}.^2;
    end
    r = sqrt(total) / G;
end

The Best Window of Each Length

This is the search. It loops over window lengths, and for each length it handles every start at once. For one length k, the integral of every window of that length is one subtraction of the running total, done for all starts at once, so each length costs one pass over the record. hic then picks the best length. The result is the same as the double loop below gives, which the program checks.

def best_by_length(a, dt, kmax):
    """For each window length k = 1..kmax samples, the best HIC over every
    start. The prefix sum S makes each window's integral one subtraction."""
    panels = (a[1:] + a[:-1]) / 2 * dt
    S = np.concatenate([[0.0], np.cumsum(panels)])
    best = np.zeros(kmax + 1)
    start = np.zeros(kmax + 1, dtype=int)
    windows = 0
    for k in range(1, kmax + 1):
        T = k * dt
        mean = (S[k:] - S[:-k]) / T          # every window of length k at once
        h = T * np.clip(mean, 0, None)**2.5
        start[k] = np.argmax(h)
        best[k] = h[start[k]]
        windows = windows + len(h)
    return best, start, windows


def hic(a, dt, kmax):
    """HIC with windows up to kmax samples: (value, start, end, windows)."""
    best, start, windows = best_by_length(a, dt, kmax)
    k = int(np.argmax(best))
    return best[k], start[k], start[k] + k, windows
function [best, start, windows] = best_by_length(a, dt, kmax)
    % For each window length k = 1..kmax samples, the best HIC over every
    % start. The prefix sum S makes each window's integral one subtraction.
    panels = (a(2:end) + a(1:end-1)) / 2 * dt;
    S = [0; cumsum(panels)];
    best = zeros(kmax, 1);
    start = zeros(kmax, 1);
    windows = 0;
    for k = 1:kmax
        T = k * dt;
        mean_a = (S(k+1:end) - S(1:end-k)) / T;   % every window of length k at once
        h = T * max(mean_a, 0).^2.5;
        [best(k), start(k)] = max(h);
        windows = windows + numel(h);
    end
end


function [value, i, j, windows] = hic(a, dt, kmax)
    % HIC with windows up to kmax samples: the value, its first and last sample,
    % and how many windows were looked at.
    [best, start, windows] = best_by_length(a, dt, kmax);
    [value, k] = max(best);
    i = start(k);
    j = start(k) + k;
end

The Plain Double Loop

This is the same search written the plain way, one start and one end at a time, as a check on the version above. It visits the same windows and should find the same HIC, and the report uses it to confirm the faster version. The MATLAB file also defines with_commas here, which writes a large whole number with commas, as Python's {n:,} does.

def hic_loops(a, dt, kmax):
    """The same search as two plain loops, as a check on the numpy version."""
    a = list(a)
    S = [0.0]
    for i in range(1, len(a)):
        S.append(S[-1] + (a[i] + a[i - 1]) / 2 * dt)
    best = 0.0
    for i in range(len(a) - 1):
        last = min(i + kmax, len(a) - 1)
        for j in range(i + 1, last + 1):
            mean = (S[j] - S[i]) / ((j - i) * dt)
            if mean > 0:
                best = max(best, (j - i) * dt * mean**2.5)
    return best
function best = hic_loops(a, dt, kmax)
    % The same search as two plain loops, as a check on the version above.
    S = zeros(numel(a), 1);
    for i = 2:numel(a)
        S(i) = S(i - 1) + (a(i) + a(i - 1)) / 2 * dt;
    end
    best = 0.0;
    for i = 1:numel(a) - 1
        last = min(i + kmax, numel(a));
        for j = i + 1:last
            mean_a = (S(j) - S(i)) / ((j - i) * dt);
            if mean_a > 0
                best = max(best, (j - i) * dt * mean_a^2.5);
            end
        end
    end
end


function s = with_commas(n)
    % A whole number written with commas between thousands, as Python's {n:,} does.
    s = regexprep(sprintf('%d', n), '(\d)(?=(\d{3})+$)', '$1,');
end

Running It Yourself

Both versions are downloads: a6_hic_search.py and a6_hic_search.m. Unzip a data pack, put the program in the pack's top folder beside crash and shots, and run it from there (Files and libraries explains why the folder matters). In Colab, upload the program beside your unzipped pack and run it in a cell with %run a6_hic_search.py (the Colab guide shows how). On your own pack it reads your data, so its numbers will differ from the ones above. The MATLAB version should run as it is in MATLAB R2018b or later. GNU Octave, which is free, needs a script's functions defined before they are used, so to run it there, move the functions to the top of the file and put a line 1; above them.
