Reading the assignment 6 program

This page reads a6_rim_crossing.py, the program behind the technical report in the assignment 6 example reports, one section at a time. The program predicts when and where each of the 12 short-record shots comes down through rim height. It fits the few frames of flight in each record, finds the falling crossing by bisection, and calls the shot in, out or too close. Before that it tries the same method on the training arcs, cut to the same length, to see how far its predictions might be trusted. Each section below shows the Python beside a MATLAB version that prints exactly the same output (checked by running both on the example pack, the MATLAB version in GNU Octave), and the line notes say what each line does and which lines carry a decision.

Program shape I suggests reading unfamiliar code by finding what comes in, what goes out and the state each loop builds, and the next section starts there. In the Python file the functions come first and the main part follows, from the top down. A MATLAB script has to keep its functions at the end, so its line ranges jump. A line you cannot read is usually covered on one of the Reading Python pages, which the notes link to, and the MATLAB lines have notes of their own. For each function the program calls, the Function cheat sheet says what it does and gives the MATLAB that does the same work.

Where the Hand Lets Go

The file does not say when the ball leaves the hand. accel estimates the vertical acceleration at every frame from a parabola through the 9 frames centered on it, since a parabola's acceleration is twice its t² coefficient. While the hand is pushing, the acceleration is upward, and last_push finds the last frame before the top where it still is. The flight is taken to start at the frame after that. Assignment 5's release rule went one step further and looked for four settled estimates in a row, but on a short record the estimates stop a few frames after the push, so this program keeps only the first step.

def accel(t, z):
    """Vertical acceleration at every frame, from a parabola through the 9 frames
    centered on it. NaN where the window runs off either end."""
    h = WINDOW // 2
    a = np.full(len(t), np.nan)
    for i in range(h, len(t) - h):
        c = np.polyfit(t[i - h:i + h + 1] - t[i], z[i - h:i + h + 1], 2)
        a[i] = 2 * c[0]
    return a


def last_push(t, z):
    """The last frame before the top where the acceleration is upward, meaning
    the hand is still on the ball."""
    a = accel(t, z)
    top = int(np.argmax(z))
    last = None
    for i in range(top):
        if a[i] > 0:
            last = i
    return last
function a = accel(t, z, WINDOW)
    % Vertical acceleration at every frame, from a parabola through the 9 frames
    % centered on it. NaN where the window runs off either end.
    h = floor(WINDOW / 2);
    a = nan(numel(t), 1);
    for i = h+1:numel(t)-h
        c = polyfit(t(i-h:i+h) - t(i), z(i-h:i+h), 2);
        a(i) = 2 * c(1);
    end
end

    % the hand is still on the ball. Empty if there is no such frame.

    end
end

The Two Fits

fit_height fits the ball's height with a parabola by least squares, either with gravity held (the t² coefficient set to −g/2 in advance) or with all three coefficients from the data. The held case moves the known term over to the measurements and fits a straight line to what is left, as Linearity in the parameters explains. fit_line fits a straight line, which is the model for each floor coordinate.

def fit_height(t, z, held):
    """Parabola z = c0 + c1 t + c2 t^2, with c2 = -g/2 when gravity is held."""
    if held:
        A = np.column_stack([np.ones_like(t), t])
        c = np.linalg.lstsq(A, z + 0.5 * G * t ** 2, rcond=None)[0]
        return np.array([c[0], c[1], -G / 2])
    A = np.column_stack([np.ones_like(t), t, t ** 2])
    return np.linalg.lstsq(A, z, rcond=None)[0]


def fit_line(t, v):
    """Straight line v = b0 + b1 t (no drag, so the floor speed is constant)."""
    A = np.column_stack([np.ones_like(t), t])
    return np.linalg.lstsq(A, v, rcond=None)[0]
function c = fit_height(t, z, held, G)
    % Parabola z = c0 + c1 t + c2 t^2, with c2 = -g/2 when gravity is held.
    if held
        A = [ones(size(t)), t];
        c2 = A \ (z + 0.5 * G * t.^2);
        c = [c2(1); c2(2); -G / 2];
        return
    end
    A = [ones(size(t)), t, t.^2];
    c = A \ z;
end


function b = fit_line(t, v)
    % Straight line v = b0 + b1 t (no drag, so the floor speed is constant).
    A = [ones(size(t)), t];
    b = A \ v;
end

Bisection on the Falling Side

The crossing is a root of f(t) = z(t) − 3.048, and above_rim is that f. falling_crossing runs bisection on it. The bracket starts at the top of the fitted parabola, where the ball is above the rim, and ends 2 s later, where it is long past. A downward parabola only falls after its top, so the one root in that bracket is the falling crossing. The rising crossing comes before the top, outside the bracket. Each pass halves the bracket and keeps the half where f changes sign, until the bracket is TOL_T wide.

def above_rim(c, t, rim):
    """f(t): how far the fitted ball is above rim height at time t."""
    return c[0] + c[1] * t + c[2] * t ** 2 - rim


def falling_crossing(c, rim):
    """Bisection on f between the top of the parabola and 2 s after it. The
    parabola is above the rim at its top and only falls after it, so the one
    root in that bracket is the falling crossing. Returns the root and the
    number of evaluations of f."""
    a = -c[1] / (2 * c[2])          # time of the top
    b = a + 2.0
    fa = above_rim(c, a, rim)
    fb = above_rim(c, b, rim)
    if fa <= 0 or fb >= 0:
        return None, 2              # the fitted ball never gets above the rim
    evals = 2
    while b - a > TOL_T:
        m = (a + b) / 2
        fm = above_rim(c, m, rim)
        evals = evals + 1
        if fm > 0:
            a = m                   # still above the rim, so the root is later
        else:
            b = m
    return (a + b) / 2, evals
function f = above_rim(c, t, rim)
    % f(t): how far the fitted ball is above rim height at time t.
    f = c(1) + c(2) * t + c(3) * t^2 - rim;
end


function [root, evals] = falling_crossing(c, rim, TOL_T)
    % Bisection on f between the top of the parabola and 2 s after it. The
    % parabola is above the rim at its top and only falls after it, so the one
    % root in that bracket is the falling crossing.
    a = -c(2) / (2 * c(3));        % time of the top
    b = a + 2.0;
    fa = above_rim(c, a, rim);
    fb = above_rim(c, b, rim);
    root = [];
    evals = 2;
    if fa <= 0 || fb >= 0
        return                     % the fitted ball never gets above the rim
    end
    while b - a > TOL_T
        m = (a + b) / 2;
        fm = above_rim(c, m, rim);
        evals = evals + 1;
        if fm > 0
            a = m;                 % still above the rim, so the root is later
        else
            b = m;
        end
    end
    root = (a + b) / 2;
end

One Prediction

predict puts the pieces together for one shot. It fits the chosen frames, finds the falling crossing, and evaluates the two straight lines at that time to say where the ball is. The positions are measured from the hoop center, so the distance from the hoop is the length of (x, y).

def predict(s, first, last, rim, held=True):
    """Fit frames first..last of shot s and return the crossing time, where the
    ball is then (x and y from the hoop center, m) and the evaluations used."""
    t = np.array(s['t'][first:last + 1])
    c = fit_height(t, np.array(s['z'][first:last + 1]), held)
    tc, evals = falling_crossing(c, rim)
    if tc is None:
        return None
    bx = fit_line(t, np.array(s['x'][first:last + 1]) - s['hoop_x'])
    by = fit_line(t, np.array(s['y'][first:last + 1]) - s['hoop_y'])
    return tc, bx[0] + bx[1] * tc, by[0] + by[1] * tc, evals
function pr = predict(s, first, last, rim, held, G, TOL_T)
    % Fit frames first..last of shot s. Returns [crossing time, x and y from the
    % hoop center (m), evaluations], or empty if there is no crossing.
    t = s.t(first:last);
    c = fit_height(t, s.z(first:last), held, G);
    [tc, evals] = falling_crossing(c, rim, TOL_T);
    pr = [];
    if isempty(tc)
        return
    end
    bx = fit_line(t, s.x(first:last) - s.hoop_x);
    by = fit_line(t, s.y(first:last) - s.hoop_y);
    pr = [tc, bx(1) + bx(2) * tc, by(1) + by(2) * tc, evals];
end

In, Out or Too Close

A ball whose center comes down closer to the hoop center than the in radius clears the rim, and one farther than the out radius cannot touch it. call narrows both bands by a margin, so a shot is only called when its predicted point would stay in the band if it moved by that much. Both radii treat the ball as coming straight down, so they sort real shots, which arrive at an angle, only roughly.

def call(d, in_r, out_r, margin):
    """In, out or too close, with the bands narrowed by the margin."""
    if d + margin < in_r:
        return 'in'
    if d - margin > out_r:
        return 'out'
    return 'too close'
function word = call_shot(d, in_r, out_r, margin)
    % In, out or too close, with the bands narrowed by the margin.
    if d + margin < in_r
        word = 'in';
    elseif d - margin > out_r
        word = 'out';
    else
        word = 'too close';
    end
end

Where a Whole Flight Ends

The training check needs a reference crossing for each arc. This function finds the last frame of a training arc that is still 1 m or more from the hoop, measured across the floor, so a fit up to it covers the whole flight before the ball is likely to touch the rim (the out radius is 0.348 m).

def near_hoop_end(s):
    """Last frame at least NEAR_HOOP from the hoop, measured across the floor."""
    dx = np.array(s['x']) - s['hoop_x']
    dy = np.array(s['y']) - s['hoop_y']
    return int(np.argmax(np.hypot(dx, dy) < NEAR_HOOP)) - 1
function e = near_hoop_end(s, NEAR_HOOP)
    % Last frame at least NEAR_HOOP from the hoop, measured across the floor.
    dist = hypot(s.x - s.hoop_x, s.y - s.hoop_y);
    e = find(dist < NEAR_HOOP, 1) - 1;
end

How the Training Records End

Before using the training arcs, the program checks two things about how they end. The header says each record runs 15 frames past the rim crossing, and three do not. It also looks for arcs whose height rises again between the last frame 1 m from the hoop and the first frame under the rim, which likely means the ball bounced off the rim or the backboard first. On those arcs the crossing the frames record comes after the bounce, so the training check below compares each prediction with a fit to the flight before the bounce.

The Training Check

Each training arc is predicted twice, from the 7 frames after its last push and from its whole flight up to 1 m from the hoop, and the two crossings are compared. The difference in time is the time error, and the distance between the two crossing points is the place error. The whole flight's crossing is a fit as well, so the check probably shows the cost of having only 7 frames, more than the model's own error. The 7 frames are also fitted with gravity free, to see whether holding it still helps on so few frames. The median place error becomes the margin used for the calls.

The Twelve Short Records

This section runs the method on the 12 records Bob asked about. Each record is fitted from the frame after its last push to its end, its falling crossing is found, and it is called with the margin. As a check, the same parabola is solved with the quadratic formula, and the program stops if the two roots disagree. The loop also counts steps between fitted frames that are not 40 ms, as a 25 Hz tracker should give (an uneven step may move a fit a little).

Two MATLAB Helpers

The MATLAB version needs two small functions the Python version does without. find_shot returns the record with a given id, which the Python version does with a loop and break. true_false turns a yes/no value into the text True or False, so both versions print the training lines the same way.

function s = find_shot(shots, wanted)
    % The shot whose id is wanted.
    for m = 1:numel(shots)
        if shots(m).id == wanted
            s = shots(m);
            return
        end
    end
end


function w = true_false(x)
    % Python prints a yes/no value as True or False, so the MATLAB version does too.
    if x
        w = 'True';
    else
        w = 'False';
    end
end

Running It Yourself

Both versions are downloads: a6_rim_crossing.py and a6_rim_crossing.m. Unzip a data pack, put the program in the pack's top folder beside crash and shots, and run it from there (Files and libraries explains why the folder matters). In Colab, upload the program beside your unzipped pack and run it in a cell with %run a6_rim_crossing.py (the Colab guide shows how). On your own pack it reads your data, so its numbers will differ from the ones above. The MATLAB version should run as it is in MATLAB R2018b or later. GNU Octave, which is free, needs a script's functions defined before they are used, so to run it there, move the functions to the top of the file and put a line 1; above them.
