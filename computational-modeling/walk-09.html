Reading the assignment 8 program

This page reads a8_noise_intervals.py, the program behind the technical report in the assignment 8 example reports, one section at a time. The program puts an interval on the driver's HIC15. It measures the noise in the 50 ms before impact, then adds noise like it to the record and reruns the whole calculation 1000 times, for two models of the noise. The spread of the 1000 answers gives the interval. Last, it changes the two choices that were held fixed, one at a time, to compare how far each moves the answer with the interval's width. Each section shows the Python beside a MATLAB version that does the same steps, and the line notes say what each line does.

The two versions draw different random numbers, so their intervals differ a little. Everything that does not depend on the draws prints the same in both (checked by running both on the example pack, the MATLAB version in GNU Octave). There the intervals' ends agree to within 0.04. Program shape I suggests reading unfamiliar code by finding what comes in, what goes out and the state each loop builds, and the next section starts there. In the Python file the functions come first and the main part follows, from the top down. A MATLAB script has to keep its functions at the end, so its line ranges jump. A line you cannot read is usually covered on one of the Reading Python pages, which the notes link to, and the MATLAB lines have notes of their own.

The Filter

The CFC filter is the one from Smoothing and phase lag, copied in. J211 sets class 1000 for head acceleration. It runs forward over the record and then backward over the result, so the two passes' delays cancel.

def cfc(y, dt, cls):
    """SAE J211-1 four-pole Butterworth (Smoothing notes), forward then backward."""
    wd = 2 * math.pi * cls * 2.0775
    wa = math.tan(wd * dt / 2)
    d = 1 + math.sqrt(2) * wa + wa ** 2
    a0 = wa ** 2 / d
    b1 = -2 * (wa ** 2 - 1) / d
    b2 = (-1 + math.sqrt(2) * wa - wa ** 2) / d

    def one_pass(x):
        out = np.zeros(len(x))
        for i in range(2, len(x)):
            out[i] = (a0 * x[i] + 2 * a0 * x[i - 1] + a0 * x[i - 2]
                      + b1 * out[i - 1] + b2 * out[i - 2])
        return out

    forward = one_pass(y)
    backward = one_pass(forward[::-1])
    return backward[::-1]
function out = cfc(y, dt, cls)
    % SAE J211-1 four-pole Butterworth (Smoothing notes), forward then backward.
    wd = 2 * pi * cls * 2.0775;
    wa = tan(wd * dt / 2);
    d = 1 + sqrt(2) * wa + wa^2;
    a0 = wa^2 / d;
    b1 = -2 * (wa^2 - 1) / d;
    b2 = (-1 + sqrt(2) * wa - wa^2) / d;
    c = [a0, b1, b2];
    forward = one_pass(y, c);
    backward = one_pass(flip(forward), c);
    out = flip(backward);
end


function out = one_pass(x, c)
    a0 = c(1);
    b1 = c(2);
    b2 = c(3);
    out = zeros(size(x));
    for i = 3:numel(x)
        out(i) = a0 * x(i) + 2 * a0 * x(i-1) + a0 * x(i-2) ...
                 + b1 * out(i-1) + b2 * out(i-2);
    end
end

HIC

The search loops over window lengths up to 15 ms. For one length, a running total of the integral gives every window's integral by one subtraction, so all the starts are handled at once. Only the value is kept, since the reruns need nothing else.

def hic(a, dt, limit_ms):
    """Largest HIC over every window up to limit_ms, a = resultant in g.
    Prefix sum of the trapezoid integral, one numpy pass per window length."""
    panels = (a[1:] + a[:-1]) / 2 * dt
    S = np.concatenate([[0.0], np.cumsum(panels)])
    kmax = round(limit_ms / 1000 / dt)          # the limit in samples
    best = 0.0
    for k in range(1, kmax + 1):
        T = k * dt
        mean = np.clip((S[k:] - S[:-k]) / T, 0, None)   # every window of length k at once
        best = max(best, np.max(T * mean ** 2.5))
    return best
function best = hic(a, dt, limit_ms)
    % Largest HIC over every window up to limit_ms, a = resultant in g.
    % Prefix sum of the trapezoid integral, one pass per window length.
    panels = (a(2:end) + a(1:end-1)) / 2 * dt;
    S = [0; cumsum(panels)];
    kmax = round(limit_ms / 1000 / dt);         % the limit in samples
    best = 0;
    for k = 1:kmax
        T = k * dt;
        mean_a = max((S(k+1:end) - S(1:end-k)) / T, 0);   % every window of length k at once
        best = max(best, max(T * mean_a.^2.5));
    end
end

The Whole Calculation

pipeline is the whole calculation in one function: filter each channel, form the resultant in g, and search for HIC15. Every rerun calls it, and so does each change to a fixed choice, so all of them do exactly the same steps.

def pipeline(chs, dt, cls=1000, limit_ms=15, g=G):
    """The whole analysis: filter each component, resultant in g, HIC search.
    cls=None skips the filter."""
    if cls is not None:
        filtered = []
        for c in chs:
            filtered.append(cfc(c, dt, cls))
        chs = filtered
    total = 0
    for c in chs:
        total = total + c ** 2
    return hic(np.sqrt(total) / g, dt, limit_ms)
function v = pipeline(chs, dt, cls, limit_ms, g)
    % The whole analysis: filter each component, resultant in g, HIC search.
    % An empty cls skips the filter.
    if ~isempty(cls)
        for m = 1:numel(chs)
            chs{m} = cfc(chs{m}, dt, cls);
        end
    end
    total = 0;
    for m = 1:numel(chs)
        total = total + chs{m}.^2;
    end
    v = hic(sqrt(total) / g, dt, limit_ms);
end

Autocorrelation

The autocorrelation at a lag says how much each sample resembles the one that many samples later. It is the correlation between the noise and a copy of itself shifted by the lag: near 1 when neighbors move together, and 0 for noise that is independent from sample to sample.

def autocorr(r, lag):
    """Correlation between the noise and itself shifted by lag samples."""
    return np.corrcoef(r[:-lag], r[lag:])[0, 1]
function c = autocorr(r, lag)
    % Correlation between the noise and itself shifted by lag samples.
    if numel(r) - lag < 2
        c = NaN;                         % too few pairs left, as numpy gives nan
        return
    end
    cc = corrcoef(r(1:end-lag), r(1+lag:end));
    c = cc(1, 2);
end

Two Models of the Noise

The two functions make one record's worth of noise each time they are called. The first draws each sample on its own from a normal distribution with the pre-impact spread. The second cuts 10 ms pieces at random from the pre-impact record itself and joins them (10 ms at this pack's rate), so each piece keeps the way the real noise wanders.

def independent_noise(pre, n, rng):
    return rng.normal(0, np.std(pre), n)


def block_noise(pre, n, rng):
    """Join random 10 ms pieces of the (mean-removed) pre-impact record."""
    r = pre - np.mean(pre)
    pieces = []
    for k in range(n // BLOCK + 1):
        s = rng.integers(0, len(r) - BLOCK + 1)     # a random start
        pieces.append(r[s:s + BLOCK])
    return np.concatenate(pieces)[:n]
function noise = independent_noise(pre, n, block)
    % Gaussian noise with the pre-impact record's sigma. block is not used.
    noise = std(pre, 1) * randn(n, 1);
end


function noise = block_noise(pre, n, block)
    % Join random 10 ms pieces of the (mean-removed) pre-impact record.
    r = pre - mean(pre);
    pieces = [];
    for k = 1:floor(n / block) + 1
        s = randi(numel(r) - block + 1);        % a random start, counted from 1
        pieces = [pieces; r(s:s + block - 1)];
    end
    noise = pieces(1:n);
end

Percentiles in MATLAB

MATLAB's own prctile reads percentiles by a slightly different rule from numpy's, so the MATLAB version has a small function that follows numpy's rule.

function p = percentile(d, q)
    % The q-th percentile, found the way numpy's np.percentile does by default:
    % sort, then go a fraction q/100 of the way from the first value to the last,
    % reading between two values on a straight line.
    d = sort(d);
    pos = (numel(d) - 1) * q / 100 + 1;
    lo = floor(pos);
    hi = min(lo + 1, numel(d));
    p = d(lo) + (pos - lo) * (d(hi) - d(lo));
end

The Reruns

This part computes HIC15 on the record, then for each noise model reruns the whole calculation 1000 times, each time with fresh noise added to all three raw channels. The random number generator is started from a fixed seed, so a run gives the same answers every time.

What Was Held Fixed

Two choices were held fixed in every rerun: the size of one g, and leaving the baseline before impact in. The program changes each on its own, recomputes HIC15, and gives the shift as a fraction of the 95% interval's width under the blocks model. A fraction well below 1 means the choice moves the answer less than the noise does.

Running It Yourself

Both versions are downloads: a8_noise_intervals.py and a8_noise_intervals.m. Unzip a data pack, put the program in the pack's top folder beside crash and shots, and run it from there (Files and libraries explains why the folder matters). On your own pack it reads your data, so its numbers will differ from the ones above. Check the stretch before impact first. On many packs it is 20 or 30 ms, and at 10,000 samples a second a 20 ms stretch is exactly 200 samples, one block, so the blocks interval comes out with no width. The figures' titles and the block length in the legend are typed in for the example test. The MATLAB version should run as it is in MATLAB R2018b or later. GNU Octave, which is free, needs a script's functions defined before they are used, so to run it there, move the functions to the top of the file and put a line 1; above them.
