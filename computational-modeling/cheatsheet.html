Function cheat sheet

This page lists every function and method that the course's Python code calls, from print to np.linalg.lstsq. Each row gives what the call does, a small example with what it gives back, the MATLAB that does the same work, and the page where the course first uses it. The examples were run in Python, and each MATLAB example was run in Octave and checked against it, so each value shown is what the code gives.

The functions a program defines for itself, such as peak or running_integral, are not here. They are explained on the page that shows the program. The Reading Python pages explain the rest of the language (names, lists, loops and so on), and Every term defines the words the course uses.
