Reading the assignment 3 program

This page reads a3_velocity_and_crush.py, the program behind the technical report in the assignment 3 example reports, one section at a time. The program integrates the crossmember's acceleration once to get the car's change in velocity since contact, compares it with the lab's measured speed, then adds the lab's speed as the constant of integration and integrates again to get the distance the compartment traveled before it stopped, the crush. It then changes each processing choice in turn to see how much the answers move. Each section shows the Python beside a MATLAB version that prints the same results (checked by running both on the example pack, the MATLAB version in GNU Octave), and the line notes say what each line does.

The integration is the running trapezoid sum from Cumulative integration. Program shape I suggests reading unfamiliar code by finding what comes in, what goes out and the state each loop builds, and the next section starts there. In the Python file the functions come first and the main part follows, from the top down. A MATLAB script has to keep its functions at the end, so its line ranges jump. A line you cannot read is usually covered on one of the Reading Python pages, which the notes link to, and the MATLAB lines have notes of their own.

The Running Integral

This function integrates a record from its first sample to every sample. Each panel is the area under the curve between two neighboring samples, and the running total of the panels is the integral up to each sample. A 0 goes in front, so the result has one value per sample and lines up with the times. The rectangle rule is there for one of the checks.

def running_integral(y, dt, rule='trapezoid'):
    """Cumulative integral with the leading zero, so it lines up with t."""
    if rule == 'trapezoid':
        panels = (y[1:] + y[:-1]) / 2 * dt
    else:                                  # rectangle, left-hand sample
        panels = y[:-1] * dt
    return np.concatenate([[0.0], np.cumsum(panels)])
function out = running_integral(y, dt, rule)
    % Cumulative integral with the leading zero, so it lines up with t.
    if strcmp(rule, 'trapezoid')
        panels = (y(2:end) + y(1:end-1)) / 2 * dt;
    else                                   % rectangle, left-hand sample
        panels = y(1:end-1) * dt;
    end
    out = [0; cumsum(panels)];
end

One Analysis

This function does the whole method for one set of choices: remove the offset or not, and which integration rule. The main part calls it once with the standard choices and again for each check, so every check runs exactly the same steps. It integrates once to the change in velocity since contact, adds the constant to get the velocity, finds the first sample after contact where the velocity reaches zero, and integrates again to the distance. The crush is the distance at that sample.

def analyse(a, t, dt, lab, baseline=True, rule='trapezoid'):
    """Everything the report needs from one set of processing choices."""
    if baseline:
        a = a - np.mean(a[t < 0])      # towed at constant speed before contact
    i0 = np.argmax(t >= 0)             # the first sample at or after contact
    dv = running_integral(a, dt, rule)
    dv = dv - dv[i0]                   # change since contact
    v = lab + dv                       # the lab's speed is the constant
    stop = i0 + np.argmax(v[i0:] <= 0)  # the first sample after contact with v at or below 0
    x = running_integral(v, dt, rule)
    x = x - x[i0]
    return {'a': a, 'dv': dv, 'v': v, 'x': x, 'stop': stop,
            'peak': np.argmin(dv), 'crush': x[stop]}
function r = analyse(a, t, dt, lab, baseline, rule)
    % Everything the report needs from one set of processing choices.
    if nargin < 5
        baseline = true;
    end
    if nargin < 6
        rule = 'trapezoid';
    end
    if baseline
        a = a - mean(a(t < 0));        % towed at constant speed before contact
    end
    i0 = find(t >= 0, 1);              % the first sample at or after contact
    dv = running_integral(a, dt, rule);
    dv = dv - dv(i0);                  % change since contact
    v = lab + dv;                      % the lab's speed is the constant
    stop = i0 - 1 + find(v(i0:end) <= 0, 1);  % the first sample after contact with v at or below 0
    x = running_integral(v, dt, rule);
    x = x - x(i0);
    [~, peak] = min(dv);
    r = struct('a', a, 'dv', dv, 'v', v, 'x', x, 'stop', stop, 'peak', peak, ...
               'crush', x(stop));
end

Running It Yourself

Both versions are downloads: a3_velocity_and_crush.py and a3_velocity_and_crush.m. Unzip a data pack, put the program in the pack's top folder beside crash and shots, and run it from there (Files and libraries explains why the folder matters). In Colab, upload the program beside your unzipped pack and run it in a cell with %run a3_velocity_and_crush.py (the Colab guide shows how). On your own pack it reads your data, so its numbers will differ from the ones above. Figure 1's title, Figure 3's range (the crush runs to 852 mm on some tests) and the last 50 ms (some records end at 310 ms) are set for the example test. The MATLAB version should run as it is in MATLAB R2018b or later. GNU Octave, which is free, needs a script's functions defined before they are used, so to run it there, move the functions to the top of the file and put a line 1; above them.
