Reading the assignment 1 program

This page reads inspect_pack.py, the program behind the technical report in the assignment 1 example reports, one section at a time. The program reads the crash test in a data pack, prints the test's description and the largest value in each channel, and draws a figure of every channel. It also draws the chest displacement two ways, since its header gives a unit its values do not fit. It uses only plain Python lists and loops, without numpy, so every step is written out. Each section shows the Python beside a MATLAB version that prints the same results (checked by running both on the example pack, the MATLAB version in GNU Octave), and the line notes say what each line does.

If this is your first program, it may help to read Program shape I first. It suggests reading unfamiliar code by finding what comes in, what goes out and the state each loop builds, and the next section starts there. In the Python file the functions come first and the main part follows, from the top down. A MATLAB script has to keep its functions at the end, so its line ranges jump. A line you cannot read is usually covered on one of the Reading Python pages, which the notes link to, and the MATLAB lines have notes of their own.

Loading the Test

The first function opens the one file in the pack's crash folder and reads it. A JSON file becomes a dictionary, so test['vehicle'], test['test'] and test['channels'] are the parts of the file.

def load_test(pack):
    """The crash folder holds one file, the test."""
    folder = os.path.join(pack, 'crash')
    name = glob.glob(os.path.join(folder, '*.json'))[0]
    with open(name) as f:
        return json.load(f)
function test = load_test(pack)
    % The crash folder holds one file, the test.
    files = dir(fullfile(pack, 'crash', '*.json'));
    test = jsondecode(fileread(fullfile(pack, 'crash', files(1).name)));
end

The Times

A channel stores its samples but not their times. Its header gives the time of the first sample (t0), the time between samples (dt) and the number of samples (n), and this function builds the times from those, in milliseconds.

def times_ms(ch):
    """The file stores no times. t0, dt and n give them, here in milliseconds."""
    t = []
    for i in range(ch['n']):
        t.append(1000 * (ch['t0'] + i * ch['dt']))
    return t
function t = times_ms(ch)
    % The file stores no times. t0, dt and n give them, here in milliseconds.
    t = zeros(ch.n, 1);
    for i = 1:ch.n
        t(i) = 1000 * (ch.t0 + (i - 1) * ch.dt);
    end
end

Micrometers to Millimeters

The chest displacement's header says meters, but its values fit micrometers (see the report's Errors and Anomalies). This function divides every value by 1000 to give millimeters.

def micrometers_to_mm(y):
    """Every value divided by 1000."""
    out = []
    for v in y:
        out.append(v / 1000)
    return out
function out = micrometers_to_mm(y)
    % Every value divided by 1000.
    out = zeros(size(y));
    for k = 1:numel(y)
        out(k) = y(k) / 1000;
    end
end

The Largest Value in Each Channel

For each channel the loop finds the largest value, ignoring its sign, and when it happens, and prints one row of the table. A crash decelerates the car and its occupants, so most of the largest values are negative. Accelerations are also given in g.

# the largest value in each channel, and when it happens
print(f"{'description':36} {'unit':8} {'largest':>9} {'in g':>6} {'at (ms)':>8}")
for key, ch in test['channels'].items():
    t = times_ms(ch)
    y = ch['y']
    i = 0                                # index of the largest size so far
    for k in range(len(y)):
        if abs(y[k]) > abs(y[i]):
            i = k
    if ch['dimension'] == 'Acceleration':
        in_g = f"{y[i] / G:6.1f}"
    else:
        in_g = '     -'
    print(f"{ch['comment']:36} {ch['unit']:8} {y[i]:9.1f} {in_g} {t[i]:8.1f}")
% the largest value in each channel, and when it happens
fprintf('%-36s %-8s %9s %6s %8s\n', 'description', 'unit', 'largest', 'in g', 'at (ms)');
keys = fieldnames(test.channels);
for m = 1:numel(keys)

One Figure per Channel

The second loop draws each channel against time, titled with the description and code from its own header, and saves it under its key. The chest displacement is converted to millimeters first, and its unit label changed to match.

# one figure per channel, labeled from its own header
for key, ch in test['channels'].items():
    y = ch['y']
    unit = ch['unit']
    dim = ch['dimension']
    if key == 'chest_d':   # header says m and 'Meters', values are micrometers
        y = micrometers_to_mm(y)
        unit = 'mm'
        dim = 'Displacement'
    plt.figure(figsize=(5, 3))
    plt.plot(times_ms(ch), y, linewidth=0.8)
    plt.axvline(0, color='gray', linestyle='--', linewidth=0.8)
    plt.title(f"{ch['comment']}  [{ch['code']}]", fontsize=9)
    plt.xlabel('time from impact (ms)')
    plt.ylabel(f"{dim} ({unit})")
    plt.tight_layout()
    plt.savefig(f"channel_{key}.svg")
    plt.close()

Running It Yourself

Both versions are downloads: inspect_pack.py and inspect_pack.m. Unzip a data pack, put the program in the pack's top folder beside crash and shots, and run it from there (Files and libraries explains why the folder matters). In Colab, upload the program beside your unzipped pack and run it in a cell with %run inspect_pack.py (the Colab guide shows how). On your own pack it reads your data, so its numbers will differ from the ones above. The MATLAB version should run as it is in MATLAB R2018b or later. GNU Octave, which is free, needs a script's functions defined before they are used, so to run it there, move the functions to the top of the file and put a line 1; above them.
