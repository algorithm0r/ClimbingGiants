Decidability vs. Recognizability

From Week 7, recall the key distinction:

  • Decidable (recursive): A language $L$ is decidable if there is a TM that always halts and accepts exactly the strings in $L$.
  • Turing-recognizable (recursively enumerable): A language $L$ is Turing-recognizable if there is a TM that accepts exactly the strings in $L$ (but may loop on strings not in $L$).

Every decidable language is Turing-recognizable (a decider is also a recognizer). The converse is false — some languages are recognizable but not decidable (Week 9).

Practical significance: A decidable problem has an algorithm that always gives an answer. A merely recognizable problem has a procedure that says "yes" when the answer is yes, but may run forever when the answer is no. For programs and proofs, we strongly prefer decidable problems.

Decidable Problems About DFAs

We can encode DFAs as strings and reason about them computationally. All of the following languages are decidable:

$A_{DFA}$ — Acceptance Problem for DFAs

$$A_{DFA} = \{\langle B, w \rangle \mid B \text{ is a DFA that accepts input string } w\} $$

Theorem: $A_{DFA}$ is decidable.

Proof: Construct TM $M$:

On input $\langle B, w \rangle$ where $B$ is a DFA and $w$ is a string:

  1. Simulate $B$ on input $w$.
  2. If the simulation ends in an accept state, accept. If it ends in a non-accept state, reject.

The simulation always terminates because DFAs always halt on finite input. $\square$

$A_{NFA}$ — Acceptance Problem for NFAs

$$A_{NFA} = \{\langle B, w \rangle \mid B \text{ is an NFA that accepts input string } w\} $$

Theorem: $A_{NFA}$ is decidable.

Proof: Convert the NFA to an equivalent DFA (Week 2), then run the $A_{DFA}$ decider.

$E_{DFA}$ — Emptiness Problem for DFAs

$$E_{DFA} = \{\langle A \rangle \mid A \text{ is a DFA and } L(A) = \emptyset\} $$

Theorem: $E_{DFA}$ is decidable.

Proof: Construct TM $M$:

On input $\langle A \rangle$ where $A$ is a DFA:

  1. Mark the start state of $A$.
  2. Repeat until no new states are marked: mark any state reachable from a marked state.
  3. If no accept state is marked, accept (language is empty). Otherwise, reject.

This is a reachability check on the DFA's state graph. $\square$

$EQ_{DFA}$ — Equivalence Problem for DFAs

$$EQ_{DFA} = \{\langle A, B \rangle \mid A \text{ and } B \text{ are DFAs and } L(A) = L(B)\} $$

Theorem: $EQ_{DFA}$ is decidable.

Proof: Construct the symmetric difference DFA:

$$C = (L(A) \setminus L(B)) \cup (L(B) \setminus L(A)) $$

$L(A) = L(B)$ iff $L(C) = \emptyset$. Run the $E_{DFA}$ decider on $C$.

The symmetric difference is constructable using DFA product construction (closure under complement and intersection). $\square$

Summary: DFA Problems

Language Description Decidable?
$A_{DFA}$ Does DFA $B$ accept $w$? Yes
$A_{NFA}$ Does NFA $B$ accept $w$? Yes
$A_{REX}$ Does regex $R$ generate $w$? Yes
$E_{DFA}$ Is $L(A) = \emptyset$? Yes
$EQ_{DFA}$ Is $L(A) = L(B)$? Yes

Decidable Problems About CFGs

$A_{CFG}$ — Acceptance Problem for CFGs

$$A_{CFG} = \{\langle G, w \rangle \mid G \text{ is a CFG that generates string } w\} $$

Theorem: $A_{CFG}$ is decidable.

Proof: Convert $G$ to Chomsky Normal Form (CNF). In CNF, every derivation of a string of length $n$ uses exactly $2n - 1$ steps. So:

On input $\langle G, w \rangle$:

  1. Convert $G$ to CNF.
  2. List all derivations of $2|w| - 1$ steps (if $w = \varepsilon$, handle separately).
  3. If any derivation generates $w$, accept. Otherwise, reject.

The number of derivations is finite (bounded by the CNF structure), so this always terminates. $\square$

Alternative: Use the CYK (Cocke-Younger-Kasami) algorithm, a dynamic programming algorithm for $A_{CFG}$ that runs in $O(n^3 |G|)$ time.

$E_{CFG}$ — Emptiness Problem for CFGs

$$E_{CFG} = \{\langle G \rangle \mid G \text{ is a CFG and } L(G) = \emptyset\} $$

Theorem: $E_{CFG}$ is decidable.

Proof: A variable is generating if it can derive a terminal string. The start variable generates a string iff $L(G) \neq \emptyset$.

On input $\langle G \rangle$:

  1. Mark all terminal symbols as generating.
  2. Repeat: mark variable $A$ if there is a rule $A \to \alpha$ where all symbols in $\alpha$ are already marked.
  3. If the start variable $S$ is marked, reject (language is non-empty). Otherwise, accept. $\square$

$EQ_{CFG}$ — Equivalence Problem for CFGs

$$EQ_{CFG} = \{\langle G, H \rangle \mid G \text{ and } H \text{ are CFGs and } L(G) = L(H)\} $$

Theorem: $EQ_{CFG}$ is undecidable.

This is surprising — DFA equivalence is decidable but CFG equivalence is not. The reason: CFLs are not closed under complement or intersection, so we cannot use the symmetric difference trick.

Summary: CFG Problems

Language Description Decidable?
$A_{CFG}$ Does CFG $G$ generate $w$? Yes
$E_{CFG}$ Is $L(G) = \emptyset$? Yes
$EQ_{CFG}$ Is $L(G) = L(H)$? No

Countable and Uncountable Sets

To understand why some languages are undecidable, we need to count how many languages exist versus how many TMs exist.

Finite, Countable, and Uncountable Sets

Finite: has a specific natural number as its size.

Countably infinite: can be put into a one-to-one correspondence with the natural numbers $\mathbb{N} = \{1, 2, 3, \ldots\}$.

Uncountably infinite: cannot be put into correspondence with $\mathbb{N}$.

Countable Sets

Examples of countable sets:

  • $\mathbb{N}$, $\mathbb{Z}$, $\mathbb{Q}$ (rationals)
  • $\Sigma^*$ for any finite alphabet $\Sigma$ (enumerate by length, then lexicographically)
  • The set of all TMs (each TM can be encoded as a string over some alphabet, and all strings are countable)
  • The set of all decidable languages

Why TMs are countable: Each TM can be encoded as a finite string. The set of all finite strings over any finite alphabet is countable (by length and lexicographic order). So the set of all TMs is at most countable.

Uncountable Sets

Theorem (Cantor): The set of all real numbers $\mathbb{R}$ is uncountable.

Proof by diagonalization: Assume $\mathbb{R}$ is countable with listing $x_1, x_2, x_3, \ldots$ Consider a real number $x$ whose $n$-th decimal digit differs from the $n$-th decimal digit of $x_n$. Then $x$ differs from every $x_i$, contradicting the assumption that all reals are listed. $\square$

The set of all languages over $\{0,1\}$ is uncountable.

Proof: Each language $L \subseteq \{0,1\}^*$ corresponds to a characteristic sequence: for the $i$-th string $s_i$ in the lexicographic enumeration of $\{0,1\}^*$, the $i$-th bit is 1 if $s_i \in L$ and 0 if $s_i \notin L$. This is a one-to-one correspondence between languages and infinite binary sequences, i.e., real numbers in $[0,1]$. Since these are uncountable, so are languages. $\square$

The Key Counting Argument

  • The set of all TMs is countable (one per string encoding)
  • The set of all languages is uncountable

Therefore, there are strictly more languages than TMs. Most languages cannot be recognized by any TM — they are beyond computation entirely.

Diagonalization

Diagonalization is a technique for constructing an object that differs from every object in a list.

Cantor's diagonalization: We already saw this for $\mathbb{R}$.

The key idea applied to languages:

Consider the infinite matrix where rows are TMs $M_1, M_2, M_3, \ldots$ and columns are strings $s_1, s_2, s_3, \ldots$. Entry $(i,j)$ is 1 if $M_i$ accepts $s_j$ and 0 otherwise.

The diagonal language:

$$D = \{s_i \mid M_i \text{ does not accept } s_i\} $$

$D$ differs from the language of $M_i$ on string $s_i$ (by construction). So $D$ is not recognized by any TM in our list. But since all TMs are in our list, $D$ is not Turing-recognizable!

This is how we prove:

  • $A_{TM}$ is Turing-recognizable but not decidable (Week 9)
  • Some languages are not even Turing-recognizable

Connections

From Week 7: TMs are defined; the Church-Turing thesis lets us use high-level algorithms.

To Week 9: We've established the counting argument (more languages than TMs), and introduced diagonalization. Week 9 applies these tools to specific undecidability proofs for $A_{TM}$ and related languages.

Why these specific problems matter:

The decidable problems about DFAs and CFGs show that we can algorithmically reason about automata and grammars. These are the "easy" cases. Week 9 shows that when we move to TMs reasoning about TMs (or reasoning about programs reasoning about programs), decidability breaks down.

The universe of languages:

All languages (uncountable)
├── Turing-recognizable
│   ├── Decidable (both L and complement are TM-recognizable)
│   │   ├── Regular
│   │   └── Context-Free
│   └── Undecidable but Turing-recognizable (e.g., ATM)
└── Not Turing-recognizable (e.g., complement of ATM)

Key theorem to preview:

Theorem: A language $L$ is decidable if and only if both $L$ and its complement $\overline{L}$ are Turing-recognizable.

This gives a useful characterization: to show undecidability, it suffices to show that either $L$ or $\overline{L}$ is not Turing-recognizable. This is sometimes easier than direct diagonalization.
